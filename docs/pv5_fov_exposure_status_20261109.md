# FOV 측광 복귀 사유 표시

2026-11-09 사용자 승인 범위는 제안 1번인 상태 표시다. 노출 알고리즘·보정·모델 입출력을
바꾸지 않으며, 제안 2번인 기존 밝기 통계 게시 시점 정리는 이번 변경에 포함하지 않는다.

## 표시와 기존 동작

기존 FOV 미리보기에서 측광 정보 아래 별도 줄을 표시한다. 추가 옵션이나 정상 주행 화면의
새 패널은 만들지 않는다. `정상 확인 중 1.2/2.0초`, `보정 정보 만료 | 기존 측광`,
`영역 잘림 | 기존 측광`, `반복 오류 잠금 | 해당 카메라 제외 후 다시 선택` 등이 표시된다.

진단은 현재 렌즈의 신선한 카메라 메시지를 최대 2Hz로 읽는다. 렌즈 전환 시 다른 렌즈의
사유를 남기지 않으며 수신 정보가 0.3초를 초과하거나 무효이면 상태 줄을 지운다.
기존 미리보기의 차량/속도/보정 유효성 조건, 2초 렌즈 교대와 경고 우선순위는 유지한다.
미리보기 자체가 닫히는 조건에서는 이 줄도 숨긴다. 이 표시는 상시 장애 경고가 아니다.

## 진단 전달

- FrameData에 `pv5ExposureFovStatus @33 :UInt8`, `pv5ExposureFovWarmupMs @34 :UInt16`만 추가한다.
- 상태 코드는 `model_fov_meter.h`와 `exposure.py`에서 동일하게 유지한다. 0은 구형/알 수 없음이다.
  구형 메시지는 기존 일반 대기/복귀 문구를 사용하며 알 수 없는 신규 코드는 미지원으로 표시한다.
- 수집기 준비/실패, 정보 대기·만료·잘못된 시각, 차량/센서 구성, 보정 미완료·잘못된 각도,
  수동 디버그·yaw 변경, 영역 잘림·버퍼·밝기 이상, 정상 확인·FOV 활성, 반복 실패·시계 잠금을 구분한다.
- 카메라별 세션과 기존 안정화 상태에서 준비 시간을 읽는다. 상태가 확인 중일 때
  1950ms를 2.0초로 반올림하여 완료처럼 표시하지 않는다.
- 이미 수행한 판단에 진단 대입과 고정 크기 메타데이터만 추가한다. 추가 히스토그램,
  이미지 복사, 모델 추론, 프레임 대기, 새 타이머/스레드/설정 읽기는 없다.

진단을 제어 조건으로 읽지 않는다. 기본값/네 가지 카메라 선택, 2초 확인, 30초 내 3회 복귀 잠금,
보정 1초/장치 2.5초 유효기간과 기존 측광·게인/센서 한계는 유지한다. Jetson 패키지를 바꾸지 않는다.

## PC 검증 범위

실제 C++ 프레임 선택 블록과 컨텍스트를 컴파일해 사유·진행 시간, 모든 카메라 선택,
8종 고장 및 렌즈별 복구·잠금을 확인한다. 동시 스냅샷의 사유 혼합 방지,
실제 cereal 왕복, 구형/미지원 코드, 진행 시간 경계, 렌즈별 UI와 만료를 검사한다.
전체 camerad 컴파일, sanitizer와 PV5 보존 검사를 함께 수행한다.

실제 C3X 그리기 함수로 합성 입력을 렌더링해 문구 배치를 확인한다.
이 검사는 실물 카메라 노출·야간 인식·스피커/EPS/CAN이나 실제 지연 검증이 아니다.
