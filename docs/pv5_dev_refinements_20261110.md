# PV5 개발 브랜치 선택 이식 및 BSD 표시 복구 — 2026-11-10

사용자 승인 범위는 레이더 식별자 연속성, 정지물체 오인 억제, 짧은 조향 개입
필터와 빌드 복구다. 이후 같은 방향 깜빡이+BSD 계기판 경고 복구도 추가했다.
기준은 배포 `8eeb8420`, 참조는 `ajouatom/openpilot`의
`joongyu01/carrot-wip-dev` 고정 커밋 `bd9f3048b4ce5e4bec7a1d58c0d9ba8a0cbf4932`다.
브랜치 전체·StopGoAssist·자동 출발·자동 크루즈 인계·SPAS 시험·Panda 변경은 가져오지 않는다.

## 적용과 범위

1. **SCC/레이더 동일 객체 식별자** — `72c77527`. 기존 모드3에서 비전 결합이
   실패해 SCC를 채택하는 경우에만, 거리 차≤2m·속도 차≤1m/s·현재 경로 안의
   실측 전방 트랙이 있으면 그 트랙과 운동값을 사용한다. 트랙이 없으면 기존
   SCC를 유지한다. 이 fallback이 다음 프레임의 비전 복귀를 추가로 지연시키지 않는다.
2. **비전 급변 직후 정지물체 확인** — `9727f3bc`, `0e262a28`. 중앙의 확인된
   움직이는 앞차가 계속 측정되고 그 앞에 새 정지 트랙이 나타나면서 비전이
   불연속으로 옮겨 붙는 경우, 기존 정지물체 확인 경로를 우선한다. 저속 이동
   차량, 기존 앞차의 감속·ID 재부여, 앞차 이탈 뒤 드러난 정지 차량, 처음 보인
   정체 꼬리와 이동 중 끼어들기를 별도로 검사한다. 새 상태는 reset·경로 소실·
   비정상/역행/긴 간격 시각에서 비운다.
3. **0.30초 조향 개입 필터** — `4bc712ea`. PV5 앵글 조향에서만 연속30틱의
   steeringPressed 후 반복 개입 횟수를 한 번 센다. 짧은 접촉을 합산하지 않는다.
   운전자 힘에 대한 즉시 양보·모델 유효성·한계·재개입·비활성화 및 기존
   `Pv5SimpleSteerRecovery` 옵션은 유지한다. 다른 차종/토크 조향은 기존 상승 에지 집계다.
4. **빌드 복구** — `9a103994`, `58f0bb92`에서 PV5/C3X에 맞춰 범위를 제한한다.
   부팅 때 네이티브 Params 없이 마지막 실제 CarParamsPersistent를 제한 크기로
   읽어 Hyundai/KIA_PV5/notCar=false를 확인한다. 불명·손상·의존성 소실이면 기존 경로다.
   별도 PV5 중단 마커를 남기고 전체 빌드와 Params 검사까지 성공해야 지운다.
   다음 부팅에 중단 마커가 있으면 기존 Rebuild All 절차를 요청한다. 빌드 실패 후
   캐시 잠금을 확보한 경우에만 빈 일반 `.o/.os/.a`를 지우고 캐시 없이 단일 작업으로
   한 번 재시도한다. 소스·비어 있지 않은 파일·`.so`·심볼릭 링크·외부 경로는 보존한다.
   다른 차종의 명시적 Rebuild All과 원래 메모리 절감 재시도는 유지한다.

레이더 helper의 새 동작은 기본 OFF이며 실제 RadarD의 CP와 오프라인 재생의
완전하고 일관된 차량 메타데이터가 PV5일 때만 켠다. 혼합/불명 재생은 기존 정책이다.
기존 모든 DPath 차종의 공통0.20초 비전 전환, 레이더 모드, 실측 CAN과 모델 입력은 유지한다.

## 지연과 검증 한계

정지한 물체가 기존 이동 앞차 바로 앞으로 옆에서 들어오는 합성 장면은 반사체와
초기 증거가 비슷하다. 이 경우 새 물체 선택에 **3프레임, 20Hz에서150ms**의
추가 확인이 관찰된다. 그동안 기존 앞차를 유지한다. 반복적인 비전 불안정과
물리 제동은 이 단일 장면 수치로 보장할 수 없다. 확인 조건을 임의로 완화하지 않는다.

모델 파일·입출력·워프·FOV·AE·Jetson 패키지·HUD 전송 우선순위·BLE·신호 정차
가상 객체·Panda 펌웨어는 바꾸지 않는다. 새 추론·워커·상시 프로파일러는 없다.
추가 레이더 처리는 PV5의 기존 RadarD 주기 안에서 실행하고 빌드 복구는 부팅에만 실행한다.
PC 회귀·합성 재생은 C3X/Orin 처리시간, EPS/ESC 수용, 실제 끼어들기 대응·안전성을 입증하지 않는다.

## BSD 계기판 표시

기존 native CCNC 코드는 같은 방향 BSD에서 배경3(주황)을 선택해 기존 주황 상태와
구분되지 않을 수 있었고, 차선 가이드는 모델의 차선 표시 조건에 묶여 있었다.
PV5에서 유효 CAN·timeout 없음·같은 방향 깜빡이+BSD이면 배경5를 유지하며,
기존20Hz 0x161 송신 안에서 가이드5(빨강)를200ms ON/200ms OFF로 표시한다.
해당 방향 BCA 표시도 유지하고 모델 차선 가시성과 분리한다. 원래 경고 문구/소리,
더 강한 off-phase 순정 표시, 패들 배경 우선순위, 카운터/CRC/송신 수는 보존한다.
조건 해제·반대 방향·입력 이상 시 원래 표시로 돌아온다. 다른 차종은 원래 바이트다.

배경5는 참조 브랜치의 신호등 표시에서 쓰는 steady-red 값이며 기존 DBC enum에는
이름이 없다. PC에서 확인하는 것은 생성 패킷의 값/주기다. 실제 PV5 계기판 색상·
표시 수용은 차량 확인이 필요하다. Jetson HUD의 기존 고정 그라데이션과2.5Hz 테두리는 변경하지 않는다.
