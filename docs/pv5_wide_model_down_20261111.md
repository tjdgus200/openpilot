# PV5 광각 모델 입력 하향 설정

캐럿웹 **PV5 → 카메라·노출 → 모델 입력·노출 → 광각 모델 입력 아래 이동**.
`Pv5WideModelDown`은 기본0, 범위0~100, 간격1이다. 저장 단위0.1°로 10=아래1°, 100=아래10°다.
0으로 되돌리면 기존 광각 변환과 동일하다. 기존 `Pv5FovPreviewPitch`는 여전히 노란 비교선 전용이다.

## 적용 경로

- 실제KIA_PV5의 가상 광각 모델 시선을 아래로 기울인다. 광각 FOV 크기 선택과 조합하며 일반각·저장된 liveCalibration은 바꾸지 않는다.
- modeld의 기존250ms 설정 확인과 보정 갱신에서만 행렬을 계산한다. 매 프레임 추가 영상복사·추론·스레드·IPC를 만들지 않는다.
- 콤마 내부 모델 및 Jetson/eGPU 전송 전의 공통 wide 변환에 적용한다. 모델 파일·입력 크기/자료형·출력 파서·반복상태 관리·조향 한계는 유지한다.
- 정차/옵션 미리보기의 청록선은 실제 입력 위치, 노란선은 그 위치를 기준으로 한 추가 비교선이다.
- 켜 둔 광각 FOV 측광도 동일 각도를 적용한다. 일반각 측광과 기존 사각 측광은 그대로다. 측광 신선도·2초 복귀 확인·실패 래치는 보존한다.
- 새 설정이 없거나 손상·범위 밖이면0이다. 새 설정은 예외 번역 없는 native `get_int` 대신 typed `get`으로 읽어 손상 값의 std::stoi 중단 위험을 피한다.

## 2026-11-12 저장값 형식 호환 수정

기존 Python 경로는 `Params.get` 결과가 정확히 `int`일 때만 적용했다. 이전 Params가
`b"10"` 또는 `"10"`을 반환하면 모델 입력과 청록선 모두 0°로 되돌리는 경로를 PC에서 재현했다.
공통 읽기 함수로 정수와 1~3자리 ASCII 숫자 저장값을 동일하게 해석한다. 범위·기본0과
250ms 읽기 주기는 유지하고, 잘못된 값·부호·공백·소수·비ASCII 값은 0으로 복귀한다.
C++ 측광의 기존 ASCII 정수 해석과도 일치한다. 광각 청록선 라벨은 0°도 항상 표시한다.

해당 실기기의 Params 반환형은 차량 종료로 확인하지 못했다. 이 재현을 사용자가 겪은
증상의 확정 원인이나 실제 차량 적용 확인으로 표현하지 않는다. 일반각·저장 보정·추론
횟수·영상 복사·IPC·모델/Jetson 패키지와 모든 제어 한계는 변경하지 않는다.

PC 결과: 수정 전 바이트·문자열 재현 8건 실패, 수정 후 전부 통과. 영구 5모델 보존
검사 3,076건 통과·실패/스킵0, 문서 생성 검사25건 통과와 사용자 문서 연결 검사 통과.
실제 모델 전송 문장과 UI 기하·C++ 측광을 검사했으며 GPU 추론·실기기 화면·지연은 미측정이다.

## 검증 범위

자동 회귀에0 복원·비PV5/notCar/단일 카메라 불변·31개 각도·FOV5종·보정3종의 방향/경계,
5개 외부 모델의 실제 Warp/JoiningModel 전달문 실행, C++ 측광 좌표 대조와 mailbox 일관성,
미리보기·설정 문서 생성을 포함한다. GPU/USB는 PC fixture 경계다.

이 변경은 콤마 전처리 설정이다. Jetson의 모델/렌더러/프로토콜과 기존5종 패키지 pin은 그대로 사용하며 재패키징하지 않는다.
콜드부팅 전부터 설정을 읽는 새 camerad/modeld 코드가 필요하므로 콤마 업데이트 후 재부팅한다.

가상 시선을 바꾸면 모델이 학습한 영상 기하와 달라지고 차선·거리·감속·조향 결과가 달라질 수 있다.
장착 높이의 정식 재보정이 아니며 인식 개선·실차 안전·실기기 처리시간을 PC 검사로 보장하지 않는다.
상한10°는 실험용 UI 범위이지 검증된 주행 안전 범위가 아니다.

## 10° 상한 확대 후속

같은 날 사용자 요청으로 최대30(3°)을100(10°)으로 확대했다. 기본0·간격1(0.1°)·기존 저장값은 유지한다.
웹3언어 설명·Python 상한·C++ 측광 상한/3자리 정수 읽기를 함께 수정했다.
0..100의101단계×5FOV×3보정 기하를 검사하고, 5개 모델 전달에5°/10°를 추가했다.
10°의 청록선·상대 노란선과 일반각 불변, 101이상/손상값0 복원도 영구 검사한다.

집중 검사745개(설정 문서25개 포함)가 통과했다. 이후 청록선10° 표시 사례도 추가해 전체 보존 검사에 포함한다.
기울기가 큰 가정 보정값에서는 영역이 영상 밖으로 잘릴 수 있다. C++ 측광의 기존90% 내부 샘플 조건과
기존 노출 복귀를5개FOV에서 확인했으며 이 조건을 완화하지 않았다. 모델 쪽 경계 처리·입력 형식·차량 제어는 그대로다.
10° 확대도 실제 인식 개선이나 실차 안전성을 검증한 것은 아니다. Jetson 패키지 재배포 없이 콤마 전처리에서 적용한다.
