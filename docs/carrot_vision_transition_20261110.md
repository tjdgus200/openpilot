## 보존·검증

원본의 움직이는 차량·정지 차량·0.20초 전환 회귀를 함께 복원한다. 실제
생성자를 여러 차종으로 실행하고 재생·MPC 입력 준비·선행차 교체·만료·
레이더 모드 경계를 검사한다. 모든 모델의 영구 체크리스트를 실행한다.

PC 검사 결과와 실제 차량 응답은 구분한다. 비전만 관측한 가까운 차량으로
전환할 때 추가 확인 시간이 생길 수 있으며, 이 작업은 근거리 끼어들기 제동
개선이나 실차 안전성을 입증하지 않는다. 차량 설치·재부팅은 수행하지 않는다.

## 조향 복귀와의 구분

이 변경은 레이더 정책만 공통으로 복원한다. `Pv5SimpleSteerRecovery`는 여전히
PV5 앵글 조향 전용·기본 OFF다. OFF는 원래 모델 불확실성·반복 개입·조향 오차에
따른 결합 handover를 사용한다. ON은 운전자 양보와 입력 유효성 조건을 유지하고
낮은 운전자 힘0.2초 확인 뒤 전체 보조력 범위를1.5초에 복귀시키는 기준을 쓴다.
실제 남은 복귀 시간은 시작 보조력과 운전자 힘에 따라 달라진다. 목표 조향각이나
CAN 한계를 확대하지 않으며 새 방식이 항상 더 빠르거나 차선 추종을 개선하지는 않는다.
