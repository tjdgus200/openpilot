# PV5 HUD 작업 기록 · 2026-11-03

이 문서는 오늘 적용한 HUD 동작과 다음 `carrot-wip` 병합에서 보존할 조건을 기록한다. 현재 동작과 검증 범위가 과거 시안보다 우선한다.

## 적용한 동작

| 항목 | 병합 시 보존할 동작 | 반영 상태 |
|---|---|---|
| PV5 차선 중앙 유지 | 기본 OFF, 캐럿웹 PV5 설정에서 주행 중 전환. 기존 크루즈·입력·차선·앞차 조건과 곡률 한계 유지. HUD는 대기·보정 방향 및 크기·레인모드·BSD 대기를 표시. | `f62d95b5` ~ `720e5729` |
| 차선 변경 대기 | 운전자 요청이 대기 중일 때 전체 HUD 중앙에 방향과 사유 표시. 사각지대 차량, 옆 차선 차량, 옆 차선 미확인, 차선 경계 조건을 구분. 제목 76px, 사유 44px 기준. 기존 시스템 경고 우선, 최신 모델 상태가 없거나 변경이 시작되면 숨김. | `8060322f` |
| 감속 이유 | 차량·차선 위에 작은 상단 배너. 종방향 제어 활성 및 최신 데이터, 감속 목표와 선택된 출처의 일치, 목표 초과 속도와 음의 계획 가속도가 모두 확인될 때 표시. 시스템 경고가 우선. | `f1fbb53a` |
| 모델 신뢰도 | 일반 주행 화면의 기존 가감속 게이지 자리에 세로 3칸. 모델 분류값의 초록 3칸·노랑 2칸·빨강 1칸과 미수신 빈 칸을 표시. 별도 신뢰도 연산이나 퍼센트 환산 없이 기존 모델 메시지의 분류값 사용. | `f1fbb53a` ~ `534d966f` |
| 게이지 배치 | 신뢰도와 조향 사이 간격을 직전 푸시 대비 16px 확대. 중앙 보정은 두 게이지 아래에서 22px 글자와 164×7px 바로 표시. | 로컬 변경 |
| Jetson 전력·온도 | 기존 별도 박스 제거. 주행 화면에서는 게이지 위에 `W | °C` 한 줄을 최대 26px 굵은 글자로 표시. 두 값의 색을 독립 적용하고 미수신은 회색 `--`. | 로컬 변경 |
| 기기 리소스 사용량 | 하단에 콤마 CPU·메모리와 Jetson CPU·메모리·GPU 표시. 주행 요약 화면에서도 유지. Jetson 샘플링은 백그라운드에서 1초 간격. FPS·추론 시간 진단을 끈 상태에서도 리소스 표시는 유지하며, 이 경우 타이밍 소켓을 조회하지 않음. | 로컬 변경 |

## 표시 색상

| 항목 | 기본 | 주황 | 빨강 |
|---|---|---|---|
| Jetson 온도 | 70°C 이하 초록 | 70°C 초과~80°C 이하 | 80°C 초과 |
| Jetson 전력 | 20W 이하 초록 | 20W 초과~30W 미만 | 30W 이상 |
| 콤마·Jetson CPU와 메모리 | 80% 미만 흰색 | 80% 이상~90% 미만 | 90% 이상 |

GPU 사용량은 기존 표시 색상을 따른다. 온도 색상과 Jetson 과열 경고는 별도 동작이며, 과열 경고는 기존 센서 트립 기준을 따른다.

## 검증 및 배포 상태

- 테스트 상태를 넣어 PC Raylib HUD 렌더러에서 전체 화면을 캡처했다. 신뢰도·조향·중앙 보정 배치와 전력·온도 줄, 리소스 하단 줄을 확인했다. 최종 색상 변경은 경계값 테스트로 확인했다.
- 마지막 HUD 관련 회귀 검사에서 63개가 통과했다. 실차 화면과 Jetson 패키지 배포는 별도로 확인해야 한다.
- `carrot-nav-pv5`에 푸시된 HUD 변경은 `534d966f`까지다. 표의 로컬 항목은 이 기록 시점의 작업 트리에 있다.
