# COMMA 추론시간 색상·1초 프레임 누락 표시 — 2026-11-11

Jetson HUD에서 기존 모델 호출시간 표시를 아래 기준으로 바꾸고 옆에
`COMMA 44.0 ms | DROP 1s:3` 형식의 누락 수를 추가했다.

- 화면 소수점 한 자리 기준: 40ms 이하 흰색, 40ms 초과~44ms 미만 주황, 44ms 이상 빨강.
- DROP 문구·개수는 항상 빨강. 기존 TRT 통계 색상은 변경하지 않는다.
- TRT와 COMMA/DROP을 상단 두 줄로 분리해 배터리 제목 겹침을 없애고 18px 글자를 유지했다.
- 기존 디코딩 주기 1Hz를 재사용하고 모델 메시지를 한 번만 읽는다.

## 누락 개수의 의미와 부하

모델 발행 쪽에서 기존 카메라 프레임 ID와 EOF 타임스탬프로 누락을 집계한다.
최근 1초 안에 확인한 모델 출력 프레임 번호 공백이며 HUD/USB 패킷 누락이나
10초 필터 비율에서 환산한 수가 아니다. 준비 전용 프레임 등의 미발행도
다음 정상 출력의 번호 공백으로 포함된다. 공백은 다음 출력이 확인한 시점에 귀속한다.
시작·프레임 번호/시각 초기화·1초 이상 관측 중단·지연·구형 메타데이터는 `--`다.

기록은 최대 64건으로 제한하고 정상 카메라 20Hz에서는 1초 이내 공백만 보존한다.
기존 modelV2에 작은 선택적 메타데이터를 추가했으며 추가 모델 추론·타이머·IPC 요청·
파일 기록·프로파일러를 만들지 않았다. 표시용 연산·직렬화 비용은 소량 추가되며
실장비 지연이 0이라고 주장하지 않는다. 제어 소비자는 없고 기존 모델 입력/출력값은 유지한다.
