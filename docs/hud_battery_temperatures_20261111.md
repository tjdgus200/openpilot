# 배터리 최고·최저 온도 배치와 표시 색상 — 2026-11-11

최고·최저 온도 숫자를 `36°C | 28°C`처럼 같은66px로 표시하고
각각의 제목을 위에, 온도차를 아래20px로 배치했다. SOC와 이번 운전 사용량
공간을 보존하며 밝은 테마에는 숫자 뒤 어두운 대비 영역을 둔다.

## 소유자 최종 지정 색상

표시되는 정수 온도 기준으로 최고·최저 각각 독립 적용한다.

| 온도 | 색상 |
| --- | --- |
| 5°C 미만 | 파랑 |
| 5~9°C | 연한 하늘색 |
| 10~30°C | 흰색 |
| 31~34°C | 노랑 |
| 35°C 이상 | 빨강 |

이는 사용자 지정 화면 표시 구간이며 차량 BMS 보호·운전/충전 허용 기준이나
경고/소리의 발동 조건을 바꾸지 않는다. 정수 표시는 기존 .0f를 유지하고
색상도 같은 정수로 판정한다. 미수신/무효는 회색--, 한쪽이 없으면 온도차도--다.
기존 필드 TTL·이전 수신값 보존·최고와 최저의 일관성 검사는 유지한다.
당초0/40/50 임시 제안은 사용자의 최종 지정으로 폐기했다.

`DROP 1s:` 글자는 흰색, 0을 포함한 유효한 비음수 숫자만 빨강,
미수신/무효--는 회색이다. 기존1Hz·원본 프레임 공백 집계와 COMMA40/44ms
색상, 모델 우선 전송, 경고 우선순위는 유지한다.
