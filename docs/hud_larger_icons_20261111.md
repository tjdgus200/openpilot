# 일반 팝업 아이콘 확대 — 2026-11-11

사용자 요청에 따라 콤마3X·Jetson HUD의 일반 안내 아이콘을 가로·세로1.8배로 키웠다.
단속·끼어들기 경계/추적/감속·구간·보호구역의 고정 그림과 차선변경/커브/방지턱의
기존 점 아이콘 모두 해당한다. 기존 글자 크기는 유지한다.

| 화면 | 기존 정적 이미지 사각형 | 확대 후 |
| --- | --- | --- |
| 콤마3X | 64.8×48.6px | 116.64×87.48px |
| Jetson HUD | 54×40.5px | 97.2×72.9px |

이는 실제 그리기 사각형의 크기다. 그림 내부의 여백·알파와 픽셀 반올림 때문에
보이는 잉크 영역의 비율은 약간 다르며, 전후 네이티브 픽셀 경계를 따로 비교했다.
콤마는 아이콘 칸을152px로 넓히고 Jetson 배지가 있으면 왼쪽으로 확장해 기존 우측 끝을
유지한다. HUD는124px 아이콘 칸과 아이콘 포함 한 줄 배너 최소100px를 사용하며,
왼쪽으로 확장해 기존 문구의 수평 위치·우측 끝·게이지 여유를 유지한다.
compact UI는 이전 그리기 명령을 그대로 유지한다.

## 보존 범위와 리소스

기존 PNG·아틀라스를 같은 해시로 재사용한다. 텍스처 종류·용량·로드/해제 횟수와
이미지/점 그리기 호출 수는 늘리지 않는다. 큰 면적으로 그리므로 실제 GPU 작업 시간이
0만큼 바뀐다고 보장하는 것은 아니다. 새 추론·타이머·통신·로깅·FPS 증가는 없다.
안내 판단/시계/캐시 함수·클래스 AST는 기존452a229b와 같다. 모델·FOV·제어·BLE·음량,
느낌표/크리티컬 화면과 자산 등22개 보호 파일은 바이트 단위로 같다.
기존1초 변형·2.5초 약한 반복·220ms 진입/퇴장·유지/종료·경고 우선순위를 보존한다.

## 검증

| 검사 | 결과 |
| --- | --- |
| 팝업·정적 타일·좁은 화면 폭/문구·경고 집중 검사 | 84개 통과 |
| 필수6그룹·5모델 PC 검사 | 2,544개 통과, 실패/스킵0 |
| 전후 × 두 실제 렌더러 × 안내11종 × 85프레임 | 3,740개 비교 프레임 |
| 실제 잉크 크기 확대·팝업 안쪽/문구·게이지 여유 | 통과 |
| compact 그리기 명령 전후 비교 | 4조건 동일 |
| 정확한5종 아카이브의 실제 확대 크기·타일·수명·기존 크리티컬 | 5/5 통과 |
| 공개 첨부 크기·SHA256 재다운로드 | 20개 일치 |

검사 수는 중복되므로 합산하지 않는다. 비교 캡처는 테두리를 포함하도록 범위를 넓혀
HUD의 전후 화면을 다시 생성했다. compact 비교 fixture의 텍스처 타입 정규화도 보완했다.
새 계측이나 상시 진단을 차량에 추가하지 않는다. PNG/GIF는 합성 입력으로 실제 UI를
렌더링한 것이며 실차/실기기 추론 성능 검증이 아니다. 차량 설치·재부팅은 미실행이다.
새 콤마 코드와 모델에 맞는 Jetson 패키지 적용이 필요하다. 이전 릴리스는 유지한다.
