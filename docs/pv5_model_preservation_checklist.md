# PV5 모델 변경 시 필수 보존·검증 목록

모델 추가·교체, Jetson 패키지 갱신, carrot-wip 병합 때마다 이 목록을 적용한다.
기능을 켜거나 안전 조건을 완화해 테스트를 통과시키지 않는다.
기준 목록은 `tools/jetlink/pv5_model_checklist.json`, 자동 실행기는
`tools/jetlink/check_pv5_models.py`다. 모델은 카탈로그에서 매번 읽으며 특정 모델만 검사하지 않는다.

## 항상 유지할 항목

2026-11-08 추가: 오프라인 추종/보정/지연 보고서는 차량 프로세스에서 실행하지 않는다.
기존 정차 AE 영역 표시는 유지한다. 명시적으로 켠 FOV 측광만 C3/C3X PV5에서
카메라 밝기 제어의 측광 입력을 바꾸며, 기본 OFF/기존 복귀·행 패딩·유효기간을 유지한다.
진입/재진입은 정상 측광 2초 후이며, 카메라별 최근 30초 내 실제 복귀 3회면 OFF/ON 또는
재시작 전까지 기존 측광을 유지한다. 무효 입력의 즉시 복귀와 원래 유효기간을 늘리지 않는다.
측광 카메라는 끔/양쪽/일반각만/광각만을 선택하며, 기존 저장값 0/1은 끔/양쪽으로 유지한다.
선택이 바뀐 렌즈만 대기·잠금을 초기화하고 다른 렌즈 및 운전자 카메라를 건드리지 않는다.
2026-11-09 복귀 사유 표시는 수집기에서 보낸 진단 코드와 준비 시간만 사용한다.
기존 미리보기 안에서만 최대 2Hz로 표시하며 미수신·만료·렌즈 전환과 구형 패킷을 처리한다.
진단값이 측광/제어 판단에 다시 들어가거나 노출 함수·유효기간·재진입 조건을 바꾸면 안 된다.
별도 표시 옵션은 주행 중에도 2초 교대를 허용하며 경고가 우선한다.
두 옵션과 메뉴 분리·잠금 없는 프레임 경로·네이티브 좌표/경계/상태 검사는
[FOV 측광 설계](pv5_fov_exposure_20261108.md)를 따른다. 모델 텐서 형상과 워프는 바꾸지 않는다.
끼어들기 상위 단계는 같은 선택 radarTrackId와 신선한 계획/측정 감속을 확인하며,
150ms 승격·기존 경고 우선순위를 다섯 모델의 배포 아카이브에서도 검사한다.
야간 인식 정확도와 실제 병목 개선은 별도 실영상/실물 증거가 필요하다.

HUD 데이터가 잠깐 또는 오래 끊겨도 열린 화면을 닫거나 boot 화면으로 재전환하지 않는다.
같은 화면에서 기존 차량 정보 만료와 연결 대기 표시를 적용한다. 최초 수신 전 대기,
명시적인 FPS 변경/시동 OFF/USB·인코더 오류/업데이트 종료 처리는 유지한다.
느린 전송 뒤 한 모델 주기의 재시도 대기를 사용하며 모델 우선 admission을 보존한다.

PV5 앵글 모드의 요구량 %는 조향각 한계와 구분한다. 별도 level3 각도 한계 경고는
실제 전송각·측정각이 설정 한계 부근이고 같은 방향의 목표각이 더 필요할 때만 표시한다.
DM과 무관한 콤마 경고음, 차량 경고 우선, 입력 만료와 수동 개입 차단 및 모든 모델의
동일한 HUD 수신·표시를 보존한다. 세부 기준은 [조향각 한계 경고](pv5_steering_angle_warning_20261107.md)를 따른다.

2026-11-07 조향각 경고 릴리스는 필수 PC 회귀 1,081건과 콤마 3X·다섯 모델의
네이티브 HUD 렌더링, 공개 파일 20개의 해시 검사를 통과했다. N16 `eda42b92`,
Flip Flop `0f109e38`, CTV3M `bce23ae5`, Light speed `24363193`, v2 `1e17a124`를
각 모델의 업데이트 대상으로 지정했다. 모델 입출력/제어는 불변이며 실차 확인은 미실시다.

## 자동 검사: 매 변경마다

PV5 단순 보조력 복귀 토글은 기본 OFF와 PV5 angle 전용 범위를 보존한다.
조향 변경 시 `test_steering_recovery.py`, `test_pv5_steering_recovery.py`,
`test_pv5_angle_limits.py`와 기존 handover 컨트롤러 검사를 추가 실행한다.
기본 OFF 전체 CAN 재생 동일성, live 전환·운전자 재개입·입력 만료·비활성화를
확인하고, 한계 정리는 기존 한계값을 높이지 않는다.

준비된 Python 3.12 Linux PC 환경에서 저장소 루트 기준으로 실행한다.
이 명령은 모델을 추론하거나 장치에 접속하지 않는다. 콤마·Jetson에서 실행하지 않는다.

```sh
PYTHONPATH=.:opendbc_repo:tools/jetlink:third_party/jetlink \
  python tools/jetlink/check_pv5_models.py --report /tmp/pv5-model-checks.json
```

- [ ] 여섯 검사 그룹이 모두 수집·실행되고 실패·스킵이 0인지 확인한다.
- [ ] JSON의 source commit, dirty 상태, 각 모델 SHA와 패키지 source가 검사 대상과 일치하는지 확인한다.
- [ ] 다섯 모델 각각에 대해 modeld의 실제 FOV polling/calibration 블록과 Warp/JoiningModel 경로를 검사한다. 카메라/GPU/USB 경계는 fixture다.
- [ ] 각 모델의 parser → 모델 메시지 → 중앙 보정 helper → 실제 controlsState 기록 블록 → HUD 직렬화/수신/표시 경로를 검사한다.
- [ ] 조건이 맞는 합성 차선에서 양방향 보정과 cruise OFF를, BSD/DM/지연/비활성/차선 모드에서 보정 차단을 검사한다.
- [ ] carrot-nav-pv5/carrot-wip의 모든 push/PR에서 `Jetson integration checks` CI와 첨부 JSON을 확인한다. 로컬 통과가 원격 CI 통과를 의미하지 않는다.

미실행·수집 오류·스킵을 통과로 취급하지 않는다. `pc_contracts_passed`는 PC 계약 검사 결과이며 아래 배포·실물 검사의 대체가 아니다.

## 모델 추가·가중치 변경 시 추가 검사

```sh
python tools/jetlink/validate_pv5_model_cpu.py \
  --model light-speed-2 --onnx /path/to/verified-model.onnx --output /tmp/pv5-model-cpu
```

- [ ] 전체 파일의 SHA·크기, 실제 입력/출력·metadata·슬라이스와 full ONNX checker를 확인한다.
- [ ] 기본 → 65 → 70 → 75 → 80 → 기본 순서로 합성 NV12의 CPU reference 입력을 만든다.
- [ ] 일반각 불변·광각 입력 변화와 12프레임의 원본/입력 패치 출력·반복 상태 완전 일치, finite와 reset 재현성을 확인한다.
- [ ] CPU reference warp 검사는 실제 QCOM/GPU warp, TensorRT FP16 또는 주행 성능 검증으로 보고하지 않는다.
- [ ] 네이티브 PC 환경에서 `test_pv5_lane_center.py`, `test_lateral_startup_control.py`, `test_lateral_readiness.py` 전체 제어 루프 검사를 실행한다.

## 실제 배포 아카이브 검사

```sh
python tools/jetlink/check_pv5_bundle.py \
  --model light-speed-2 --bundle /path/to/host.tar.gz --output /tmp/pv5-native-check
```

그래픽 세션이 없는 Linux PC는 Xvfb/Mesa를 사용한다. Windows는 Linux에서 생성한 합성 snapshot을 `--snapshot`으로 전달할 수 있다.

- [ ] 최종 모델별 핀과 아카이브 해시·크기·SOURCE_COMMIT 및 양쪽 spec을 대조한다.
- [ ] 저장소 import에 의존하지 않는 추출 패키지에서 server import를 확인하고 native HUD 첫 프레임·폰트를 실제 렌더링한다.
- [ ] 차선 인식도·스티어·중앙 보정, 자원 footer/W·온도, TRT 10초 AVG/P99/MAX와 콤마 모델 호출 시간이 표시되는지 확인한다. 전체 diagnostics는 OFF를 확인한다.
- [ ] 감속·조향·주행 상황 팝업은 내려오는 동작이 끝난 첫 프레임부터 최소 1초 표시하고, 신선한 사유가 계속되면 시간 제한 없이 유지한다. 사유가 끝나거나 만료되면 220ms 동안 위로 올린다. 차량 경고와 더 높은 우선순위의 팝업은 즉시 표시한다. 빨간 전방 주시 팝업은 처음부터 정착 위치에 표시한다.
- [ ] 기존 HUD 스냅샷으로 끼어들기와 차선 변경 팝업을 확인한다. 대기 상태에서는 차선 변경 중 문구를 표시하지 않는다.
- [ ] renderer 변경이면 영향을 받는 모든 모델의 패키지를 새로 만들고 다시 검사한다. 검사 도구·문서만 바뀌면 기존 패키지를 임의 재발행하지 않는다.
- [ ] 공개 배포 파일 전부를 다시 다운로드해 해시를 확인하고 결과를 남긴다.
