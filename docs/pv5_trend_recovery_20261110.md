# PV5 조향 복귀의 오차 추세 반영

사용자가 승인한 후속1번만 적용한다. 직전60231f59의 기본 OFF/PV5 angle 전용
`Pv5SimpleSteerRecovery` 안에서 보조력 상한의 회복 상승률을 조정한다.
목표각·송신각 계산, 최대각·각도 변화율·횡가속·jerk·Panda, 모델/FOV/HUD와
Jetson 패키지는 변경하지 않는다. 제어 상태 연결과 실제 EPS 지연 보정은 미적용이다.

## 동작

- 목표각/제한 후 송신각과 실제각의 두 절대 오차 변화율을 따로 계산한다.
  속도별 허용 오차폭 단위로 정규화하고 +/-10폭/s로 제한한 뒤0.15초
  1차 필터를 적용한다. 첫 표본에서는 변화율을 추정하지 않는다.
- 두 추세가 모두+0.1폭/s보다 크거나 모두-0.1폭/s보다 작을 때만 작은 쪽
  증감을 사용한다. 서로 다른 추세와 작은 잡음에는 기존 크기 기반 수요를 쓴다.
- 0.1초 look-ahead에 해당하는 보정은 허용 오차폭의 절반 이내다. 실제 오차가
  이미 기존 기준을 넘어0.1초 확인된 경우에만 추가 가속을 조정한다.
  커지면 앞당기고 줄면 낮추며, 기본 회복 상승률 아래로 낮추지 않는다.
- 기존 저힘 확인/회차별 시간 고정,0.2초 가속 비중 slew, 최대1.5배/전체범위
  1초 기준 속도, 즉시 운전자 양보와 모든 한계를 그대로 유지한다.
  추가로 올리는 속도만 줄일 수 있으며 이미 회복된 상한을 추세만으로 낮추지 않는다.
- 운전자/예비 개입, 잔여 힘, 요구 방향 불일치/반전, 입력/시간/모드 이상 시
  추세 이력도 함께 지운다. 최대 보조력에서는 추세 계산을 하지 않는다.
  새 신경망·스레드·설정 폴링·프레임별 계측을 추가하지 않는다.

필터/예측 상수는 설계 가정이며 PV5에서 식별한 물리 파라미터가 아니다.

## PC 결과와 한계

같은 실제 controller/CAN 패커와 가정한20Hz 계획기·bicycle/2차 EPS로 직전 버전과
짝지어 비교했다. 기존48조건에160ms 지연24조건을 추가한72조건이다.
속도36/54/79.2km/h, 가정 EPS 각가속180/360deg/s², 지연0/80/160ms,
일정/더 휘는 커브와 좌우를 모두 포함한다. 실제 신경망은 실행하지 않았다.

| 항목 | 기존48조건 | 확장72조건 |
| --- | --- | --- |
| 개선 / 동일 / 악화 |14 /26 /8 |24 /38 /10 |
| 최대 횡오차 감소율 중앙값 |0% |0% |
| 가장 큰 추가 악화 |0.024mm |0.024mm |
| 이전 / 변경 후 최악 최대 횡오차 |3.338 /3.338m |5.095 /5.095m |

확장72조건에서 최대 개선율은0.345%, 최대 악화율은0.0061%다. 평균적인
추가 이득이 확인됐다고 할 수 없고 큰 횡오차도 남았다. 이 결과를 실차 차선 유지,
안전성 또는 자연스러움의 입증으로 사용하지 않는다. 특정 좋은 사례만 추려 보고하지 않는다.

표시용 Float32 상한의 차분에는 두 ULP 이내 반올림 차이가 있어 시험을 분리했다.
내부 상승률은 여전히2.25단위/틱+1e-8로 엄격히 검사하고, 표시값 차분에만
2^-15 허용오차를 둔다. 차량 제어 한계를 완화한 변경이 아니다.

전후 helper를 번갈아7회, 회당30,000호출 측정한 최종 PC 중앙값은 회복 중1.68→2.95µs,
완전 회복0.98→1.03µs, OFF0.161→0.163µs였다. 할당/루프 비용을 포함한 단일 PC
측정이며 C3X/Orin 제어 주기나 모델 추론 지연을 측정한 것이 아니다.

`test_pv5_trend_recovery.py`의 추세/잡음/초기화/한계 회귀를 영구 모델 검사에
포함한다. 실제 CAN 기본 OFF/타차종/작은 오차 ON은 이전60231f59와12,000개
짝지은 프레임에서 모든 actuator/CAN 출력이 같았다. 실차 EPS 검증은 미완료다.
