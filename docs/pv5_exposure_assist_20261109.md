# PV5 도로·명암 보조 노출 — 2026-11-09

## 범위와 사용

사용자 승인 항목 1·2(도로 방향 가중 측광 + 영역별 암부/명부 보조)를
카메라별 한 옵션으로 묶는다. 캐럿웹 **설정 → PV5 → 카메라·노출 → 모델 입력·노출**의
`Pv5RoadExposureAssist`(일반각), `Pv5WideExposureAssist`(광각)는 각각 기본 OFF다.
ON이면 해당 렌즈에 보조 FOV 측광을 사용하고, OFF이면 기존 `Pv5ModelFovExposure`
선택으로 돌아간다. 따라서 기존 선택이 FOV라면 보조 OFF도 FOV이며, stock 복귀가 필요하면
기존 선택에서도 그 렌즈를 제외해야 한다. 다른 렌즈의 설정/대기/복귀 잠금은 유지한다.

KIA_PV5, C3/C3X, 기존 dual-camera/UseWideCamera 조건에서만 활성화한다. 다른 차종,
드라이버 카메라, 지원하지 않는 장치에는 기존 측광을 유지한다. 모델 입력 크기·전처리·USB·
TensorRT·조향·종방향 제어 코드는 바꾸지 않는다. 카메라에서 측광하므로 내부 모델과 Jetson
모델 모두 이후 촬영되는 영상의 노출 변화는 받는다. **노출 변경에 따른 모델 출력 동일성이나
인식 개선을 보장하지 않는다.** 별도 Jetson 패키지 변경은 없다.

## 구현

- 보정된 모델 좌표의 기존 64×36(최대 2,304개) Y 표본 위치를 그대로 사용한다.
  광각은 기존 FOV 선택을 따르며 일반각의 FOV는 바꾸지 않는다.
- 모델 투영의 수평선 아래 표본은 중앙 1/3에 가중치 3, 나머지에 2, 수평선 위에는 1을 준다.
  모든 표본을 남긴다. 이는 고정 기하학적 도로 방향 가중치이며 실제 도로/차량 분할 결과가 아니다.
- 동일 표본을 모델 좌표 3×3 영역으로 집계한다. Y≤5를 암부, Y≥250을 명부 포화로 계산한다.
  유효 표본 128개 이상인 영역만 보조 판단에 사용한다. 명부는 모든 영역, 암부는 아래 3개
  영역만 고려한다. 검은 하늘만으로 노출을 올리지 않는다.
- 균등 중앙값 대비 가중 중앙값의 보조 편향은 ±0.25 stop 이내다. 영역별 최대 명부 비율이
  10%를 넘으면 40%까지 최대 −0.125 stop의 보조를 적용하고 밝히는 방향을 막는다.
  명부 비율이 10% 이하일 때만 하단 암부 비율 25~75%에서 최대 +0.125 stop을 보조한다.
- 합산 편향은 ±0.375 stop 이내이며, 시정수 0.5초의 완화와 초당 0.4 stop의 변화율 제한을
  함께 적용한다. 처음 활성화한 프레임, 비활성화, 시간 역행, 250ms 초과 단절 시 보조 편향을
  0으로 초기화한다. 최종 측광값은 최대 1로 제한한다.
- 이 한계는 **기존 노출 제어기에 넣는 측광값의 편향 한계**다. 실제 셔터 시간·게인·영상 밝기
  또는 전체 FOV 전환 폭의 한계라는 뜻이 아니다. 기존 센서 EV/게인 제어기와 하드웨어 한계는
  그대로다. FOV→stock 복귀는 즉시 이루어지므로 모든 상황의 밝기 변화가 완만하다고 보장하지 않는다.

기존 입장 조건을 유지한다. 정상 표본 2초 연속 확인 후 활성화하고, 잘못되거나 만료된
입력/보정/장치 정보, 수동 노출, yaw 변경, 90% 미만 영역 coverage, 유효하지 않은 버퍼/밝기에는
stock으로 복귀한다. 30초 내 실제 복귀 3회면 해당 카메라를 잠근다. 해당 보조 옵션을 1초 이상
OFF 후 ON하여 재시도할 수 있다. yaw 변경에 따른 잠금은 기존대로 재부팅이 필요하다.
방법(stock/균등 FOV/보조 FOV) 변경만 해당 렌즈의 세션을 바꾼다.

설정 읽기는 기존 저우선순위 worker의 250ms 주기에 2개 bool을 추가한다. 프레임 소유자는
기존 한 번의 비대기 mailbox 조회만 한다. 보조는 기존 표본 루프 안에서 계산하고 추가 영상
복사·전체 영상 순회·모델 추론·동기화를 넣지 않는다. 프레임 전달 후 측광 순서를 유지한다.
추가 worker 설정 읽기, 표본 연산 및 캐시는 비용이 0인 것은 아니다.

## PC 검증

기준 소스: `6151d541e0ef752196a0632175d146efca224e5d`.

- 상시 PV5 체크리스트 6개 그룹: 1,600 passed, 0 failed, 0 skipped.
  N16 / Flip Flop / CTV3M / Light speed / Light speed 2 계약 검사 포함.
- 이후 미리보기 옵션 조합을 늘린 최종 집중 검사: 188 passed.
  실제 C++ 측광/worker/프레임 선택 코드를 native harness로 실행한다. 두 렌즈·5개 FOV,
  256개 방법 전환, 다른 차종 제외, 만료/수동/yaw/버퍼/복귀 잠금과 재시도를 포함한다.
- 균일 영상, 어두운 도로, 검은 하늘, 하단 암부, 역광과 암부 혼합, 흰 영상/검은 영상 합성
  장면으로 보조 방향·한계·시간 간격·리셋·유한값을 검사했다. 물리 센서/ISP 폐루프 재현은 아니다.
- 실제 `camera_qcom2.cc` translation unit을 생성된 cereal schema와 함께 PC g++로 컴파일했다.
- 설정 Wiki 생성/문법 검사 통과. 기존 다른 설정의 번역 설명 누락 경고는 남아 있으며,
  이 두 옵션에는 한국어·영어·중국어 설명을 넣었다. 다른 소유자의 upstream Wiki는 수정하지 않았다.

`tools/jetlink/benchmark_fov_exposure_assist.py`는 차량에서 실행하거나 import하지 않는
독립 PC 측광 microbenchmark다. 16개 stride 포함 영상 버퍼, 3개 합성 장면, 5라운드,
라운드당 준비 500회 후 12,000회 측정하며 baseline/OFF/ON 실행 순서를 순환한다.
다음은 각 라운드 평균 및 P99의 중앙값(단위 µs)이다.

| 장면 | 기존 평균 | 새 OFF 평균 | 새 ON 평균 | ON−OFF 평균 | ON P99 |
|---|---:|---:|---:|---:|---:|
| 균일 | 2.896 | 3.061 | 3.226 | 0.165 | 4.114 |
| 임의 밝기 | 1.570 | 1.519 | 2.925 | 1.406 | 3.651 |
| 상단 밝음·하단 어두움 | 2.302 | 2.350 | 3.106 | 0.757 | 4.604 |

세 장면 모두 baseline과 OFF의 밝기/암부/명부 누적 checksum이 정확히 같았다.
측광 객체 크기는 PC에서 9,280→13,904 bytes(객체당 +4,624 bytes)였다.
ON−OFF 추가 비용은 이 PC에서 약 0.0002~0.0014ms/회다. 기존 FOV 측광 대비 비교이며,
stock 측광 전체와의 비교나 worker I/O·보정 재계산 비용, C3X/Orin 모델 추론 지연 측정은 아니다.
실기기 타이밍 무영향, 야간 인식 향상, 폐루프 주행 안전성은 미검증이다.

## 레이더 제안의 경계

레이더가 가리키는 영상 영역을 노출의 참고로 쓰는 방식은 이번 구현에 포함하지 않는다.
향후 별도 실험은 시간 정렬·외부 보정·대상 대응 오차를 먼저 확인하고, 해당 영상 영역의
암부/포화를 확인한 뒤 제한된 측광 보조로 검토한다. 레이더 반사가 곧 차량이라는 가정,
한 프레임의 급격한 노출 실험, 추가 추론을 기다리는 제어 경로는 도입하지 않는다.
