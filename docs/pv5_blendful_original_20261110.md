# PV5 원본 Blendful 전체 포팅

이 문서는 같은 날의 `3817c32d` 근사 구현을 대체한다. 사용자의 최종 지시는
원작자에게 없는 자체 상한·차단을 없애고 원본 중앙 보정 코드를 가져오는 것이다.
앞선 보존 문구의0.08m/s²·추가 차단을 복원하면 안 된다.

## 원본과 소스 동일성

- [sunnypilot Blendful #2073](https://github.com/sunnypilot/sunnypilot/pull/2073),
  병합 커밋 `97135965effb3630ed55993903449edb73468d50`.
- 비교한 고정 원본: `sunnypilot/master`의
  `3d8f211d4b2d7c4a981633783232c8ff8dbe402b`.
- `openpilot/selfdrive/modeld/blendful.py`는 원본의 constants import 경로만
  현재 프로젝트 경로로 바꾼 파일이다. 줄바꿈을LF로 정규화하고 import를 역변환한 SHA-256은
  `652c52e164933a0fe585ef121e642f60e3e0a616554dcc9366b2231efefe5920`으로 일치한다.
- 원본 MIT 저작권 헤더를 보존했다. 사용한 `FirstOrderFilter`의 AST도 원본과
  동일하며, 양쪽 `DT_MDL=0.05`와33지점0~192m X 격자도 같다.

## 삭제한 자체 정책과 유지한 원본

삭제:0.08m/s² 추가 횡가속도 상한, 앞차/모델 lead/BSD/DM/운전자/브레이크/기어
직접 차단, 양쪽50% 확률 조건, 폭2.8~4m·중앙/경로0.3m·변화0.12m 등 별도 기하
차단,9지점 근사, 추가0.5초 dwell/ramp 및 별도 신뢰도 필터.

원본 그대로: 지점별 차선 불확실성, 차로 폭 학습·한쪽 차선 처리, 차선 소실 이력,
모델의 평소 경로 대비 회피 판단, 신뢰도와 곡률 피팅, build/release 변화율,
MIN_SPEED5m/s(18km/h) 미만 감쇠. 활성 식은 원본 ZoomPilot의
`desire == none and lane_change_state == off`이다. 앞차나 BSD 데이터 자체를
중앙 보정의 입력·차단으로 사용하지 않는다. 회피 판단은 물체의 정답 판정이 아니다.

## 통합 경계

`Pv5Blendful`은 PV5에서만 생성된다. 기존 웹 옵션 이름·기본 OFF·저장값과250ms
옵션 확인은 유지한다. 원본 ModelSettings의 다른 기능이나 전체 fork는 가져오지 않는다.

원본이 요구하는 원시 `lane_lines`, 지점별 `lane_lines_stds`, 확률과 `plan`을
modeld 파서 뒤에서 직접 읽는다. 축약된 `modelV2.laneLineStds`로 원본을 흉내내지
않는다. 계산 결과는 현재 `get_action_from_model`의 기존 smoothing 전에 한 번만
더하며, 네트워크 입력·반복 상태·추론·가속/속도/정지 출력을 바꾸지 않는다.
이 지점은 내부 CD210과 다섯 Jetson 모델의 공통 출력 처리 경로다.

Carrot의 나머지 action 계산·smoothing·경로 선택은 유지한다. 레인모드가
`lateralPlan`을 고르면 기존처럼 그 경로가 우선한다. 이를 표시하는 ‘레인모드’
상태는 원본 계산을 차단하거나 다시 쓰는 조건이 아니다.

배열 형태/유한성·정의되지 않은 수치 연산 오류는 경계에서 처리한다. 잘못된 텐서,
0 표준편차의 정의되지 않은 나눗셈, NaN/무한값이면 보정 상태만 초기화하고 추가량0을
돌려준다. 정상 입력의 원본 결과에 상한이나 별도 운전 정책을 적용하지 않는다.

모델 메시지의 새 `pv5LaneCenter @27`은 원본 결과의 읽기 전용 메타데이터다.
controls 쪽 helper는 이제 표시만 하며 보정을 계산·추가·클램프하지 않는다.
기존 controlsState69번 게이지는 원본 ZoomPilot의 lookahead 이동량을0.2m 기준
sqrt 표시한다. 0.2m는 표시 눈금이며 제어 상한이 아니다. 오래된 정보나 실제 선택되지
않은 경로는 게이지만 비운다. 원본 모델 action을 다시 쓰지 않는다.

기존 차량의 조향 활성 허용·운전자 개입 양보·각도/각속도/물리/CAN 제한은 유지한다.
이는 중앙 보정에 임의로 추가한 조건이 아닌 차량의 기존 제어·안전 경로다.
Jetson의 신경망·입출력 텐서·렌더러는 변경하지 않아 패키지를 재발행하지 않는다.
적용 위치와 메시지 스키마가 바뀌므로 **git pull 후 콤마를 재부팅**해야 한다.
modeld 또는 controlsd 한 프로세스만 새 코드로 재시작해 혼합 버전으로 운용하지 않는다.

## PC 검증

원본/이식본을 같은 원시 출력·속도·기동 상태로 비교했다. 실영상 인식이나 실차를
모사해 정확도·안전 개선을 입증한 시험은 아니다.

- 원본 소스 해시, 필터·시간 간격·격자와 원본 테스트9개를 보존한다.
- 원본/adapter 동등성, 한쪽 차선·커브·회피·저속·OFF, 삭제한0.08 초과 출력,
  원래 변화율, 비정상 수치 처리와 실제 action 삽입/종방향 불변 검사113개 통과.
- 실제 Controls 및5모델 parser→원본→메시지→controls/HUD 검사111개 통과.
  앞차/BSD/DM의 추가 차단 부재, 중복 적용 없음, OFF 및 구형 메시지를 확인했다.
-5모델 필수 보존 검사2,087개 통과, 실패0·스킵0.
- 기존 PV5 운전자 양보·보조력 복귀·각도 한계·제어 시작 회귀182개 통과.
  위 검사 그룹은 일부 겹치므로 고유 검사 수로 합산하지 않는다.
- PC 고정 입력 여섯 조건에서 각각2,000회 측정하고 원시 배열 불변성을 확인했다.
  활성 조건 평균66~78µs/P99 122~166µs, 저속 평균3.78µs, OFF1.10µs.
  추가 추론·상시 계측·worker는 없다. C3X/Orin 시간은 미측정이다.

초기 연결 시험은 NumPy 스칼라 직렬화 및 enabled 표시 상태를 바로잡았다.
HUD 한도 초과는 실제처럼 새 메시지를 만들지 않고 시험용 Cap'n Proto arena를
재사용해 목록이 누적된 문제였으며 시험을 수정했다. 실제96KiB 한도는 늘리지 않았다.

## 미검증 범위

실제 모델의 차선/회피 판단 정확도, 실제 카메라·EPS 반응·스피커·주행 안전성은
검증하지 않았다. 원본과 같은 계산이라는 사실이 실차 안전 보장은 아니다.
기본 OFF를 유지하고 기존 저장 선택을 자동 변경하지 않는다.
