# PV5 차로 중앙 추종 측광 박스 · 2026-11-09

카메라별 `Pv5RoadLaneExposure` / `Pv5WideLaneExposure`는 기본 OFF다. 캐럿웹 **설정 → PV5 → 카메라·노출 → 모델 입력·노출**에서 켠다. KIA_PV5 C3/C3X 전용이다. 이 옵션은 **측광 박스 전체를 수평 평행 이동**하며 폭·높이·세로 위치와 모델 FOV·크롭·텐서 크기는 유지한다. 이전 차로 내부 가중치 구현과 설명은 이 문서의 전체 박스 이동 방식으로 대체한다.

## 위치 추정과 전체 영역 측광

기존 modelV2의 좌우 자차 차선1/2를 이용해 앞쪽15/25/35m의 차로 중앙을 보간한다. 세 지점을 실제 카메라 rpy·내부 파라미터로 투영한 가로 위치의 평균을 목표로 사용한다. 이 거리는 제한된 초기 구현값이며 최적값이나 실차 개선이 검증된 값은 아니다. 어두운 픽셀·차선 선의 밝기·노면 색은 목표 위치 계산에 입력하지 않는다.

카메라 소유 스레드는 선택된 박스 전체에 고르게 배치된64×36 표본을 읽는다. 차로 내부 픽셀만을 추가 가중하는 마스크는 제거했다. 도로·명암 보조를 사용자가 별도로 켜 둔 경우에만 그 기존 고정 가중치와 명암 보조를 유지한다. 박스 이동만 따로 비교하려면 해당 렌즈의 도로·명암 보조를 끄고 차로 중앙 추종 박스를 켤 수 있다. 모델 입력 범위는 움직이지 않는다.

## 토글 우선순위와 복귀

| 해당 렌즈에 저장된 기본 설정 | 이동할 박스 | OFF / 차로 정보 소실 시 |
|---|---|---|
| 도로·명암 보조 ON | 기존 보조 FOV 박스 | 해당 기본 방식의 원래 위치 |
| 보조 OFF, FOV 측광 선택됨 | 기존 균등 FOV 박스 | 해당 기본 방식의 원래 위치 |
| 둘 다 아님 | 기존 자동노출 박스 | 기존 자동노출 영역 |

하위 토글은 자동으로 켜거나 끄지 않고 저장값을 유지한다. 약한/오래된 차로 정보나 차선변경 상태에서는 목표 이동량을0으로 돌리고 제한된 속도로 원래 위치로 복귀한다. 유효 정보가0.5초 지속되어야 다시 이동한다. 직접 OFF하면 위치 보조를 초기화하고 저장된 기본 방식만 사용한다. 유효 측광 방식 전환은 해당 카메라만 기존2초 확인을 다시 거칠 수 있다.

공통 보정·기하·버퍼 오류는 위 우선순위보다 우선해 즉시 기존 자동노출로 복귀한다. 기존30초 내3회 복귀 잠금도 유지한다. 영역 확인 토글은 독립적이며, UI의 보라색 윤곽은 camerad가 실제로 사용한 이동 박스이고 `BOX`로 표시한다. 안전 경고의 우선순위는 바꾸지 않는다.

## 입력·경계·변화량 제한

- 좌우 차선 확률≥0.8, 표준편차≤0.3, 4~60m에 있는 유효한 좌표·차로 폭2.2~5.5m를 요구한다. 좌표 NaN, 잘못된 순서·길이·범위, 누락된 보간 지점은 추적을 허용하지 않는다. 임의 차선을 만들지 않는다.
- modelV2 원본 카메라 EOF≤250ms와 메시지 시각≤200ms를 함께 확인한다. 오래된 결과를 재수신해도 유효기간은 늘지 않는다. 광각 FOV 변경 뒤0.5초 동안 이전 기하 출력의 만료를 기다린다. 보정·장치 TTL, yaw 변경 후 재부팅 조건은 그대로다.
- 위치 이동량의 고정64픽셀 상당 상한은 제거했다. 유한한 차로 중앙 추정값은 영상 밖에 있어도 허용하며 박스는 영상 끝에서 멈춘다. 이동 속도는 초당 모델64픽셀 상당으로 유지한다. 더 멀리 이동하면 같은 속도로 원복하는 시간도 더 길어진다. 실제 센서 픽셀로 환산하고, 네 모서리의 기존 잘림이 더 나빠지지 않도록 추가 제한한다. 유효 표본은 영상 밖이나 NV12 행 패딩을 읽지 않는다. 영상 경계에서 내부 이동 상태도 함께 제한해 누적/복귀 지연을 막는다.
- 이동한 전체 박스 밝기를 원래 위치와 비교하여 추가 측광값을±0.125stop으로 제한한다. 총 보조±0.375stop, 기존0.5s 평활·0.4stop/s 제한을 유지한다. 이동 박스의 포화가 크면 이동 보조로 인한 추가 증광을 막는다. 이동 영역이 완전히 검으면 위치 보조 증광을 적용하지 않는다.
- 기존 자동노출 영역을 기본으로 쓸 때도 해당 영역을 같은 크기로 옮긴다. 작은 표본 격자의 위치 변화량만 원래 조밀한 stock 측광값에 제한적으로 반영하므로 기존 제어기를 교체하지 않는다. 물리 셔터·게인 변화량이나 인식 개선의 보장은 아니다.

## 처리 경로와 비용

기존 nice10/SCHED_OTHER 작업자가 옵션 ON일 때만 modelV2를 추가 구독하고100ms 주기로 최신값을 읽는다. 설정 확인은250ms다. 카메라 소유 스레드는 유한한 원자적 최신값 읽기와 캐시된 정수 표본 오프셋 계산만 하며, 모델·설정 파일·IPC를 기다리지 않는다. 옵션 OFF의 작업자 주기는 기존250ms다. 추가 NN 추론·CUDA 처리·영상 워핑·복사는 없다.

위치가 바뀌면 기존2,304개 표본과 이동 위치2,304개 표본을 읽으므로 CPU/메모리 읽기 비용은 늘어난다. 실제 모델 구독·작업자 스케줄링·기존 조밀한 stock 영역 스캔·전체 추론 지연은 아래 PC 마이크로벤치마크에 포함되지 않는다. 노출이 달라지면 모델의 판단도 달라질 수 있으므로 기본 OFF를 유지한다.

### PC 측광 마이크로벤치마크

기준 `8f37939d`, C++ 최적화 빌드, 장면당5회×12,000회 계측(16프레임 풀). 새 옵션 OFF와 기존 보조 ON의 각 프레임 출력 비트 해시·합계가 변경 전과 동일했다.

| 장면 | 박스 이동 추가 평균 ms | 박스 이동+기존 보조 P99 ms |
|---|---:|---:|
| 균일 | 0.001270 | 0.006327 |
| 임의 | 0.002725 | 0.005973 |
| 명암 분리 | 0.001986 | 0.006005 |
| 포화 | 0.001435 | 0.005549 |

측광 객체는 PC 빌드에서13,984바이트다. PC 수치는 C3X/Orin 추론 지연 불변이나 야간 성능의 증거가 아니다.
