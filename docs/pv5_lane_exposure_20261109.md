# PV5 차선 추종 측광 · 2026-11-09

일반각/광각에 독립 기본 OFF 토글 `Pv5RoadLaneExposure`와 `Pv5WideLaneExposure`를 추가했다. 캐럿웹의 **설정 → PV5 → 카메라·노출 → 모델 입력·노출**에서 설정한다. KIA_PV5 C3/C3X 전용이다. 이 기능은 밝기 측정 표본의 가중치만 이동하며 모델 FOV·크롭·카메라 보정·텐서 크기는 바꾸지 않는다.

## 토글 우선순위와 복귀

기본 측광은 같은 렌즈의 **도로·명암 보조 ON → FOV 측광에 선택됨 → 기존 자동노출 영역** 순서다. 차선 추종 ON은 이 기본 측광에 제한된 추가 가중치/측광값을 더한다. 하위 설정을 자동으로 바꾸거나 저장값을 덮어쓰지 않는다. 영역 확인 토글은 독립적인 화면 표시다.

차선 정보가 약하거나 오래되거나 차선변경 상태이면 추가 가중치가 1/s로 빠지고, 보조 측광값은 평활되면서 선택된 기본 방식으로 수렴한다. 다시 0.5초 연속 정상 차선 확인 후 가중치를 1/s로 올린다. 사용자가 OFF하면 추가 가중치는 초기화한다. 유효 측광 방식 변경은 해당 렌즈만 기존 2초 확인을 재시작할 수 있다. 공통 기하·보정·버퍼 오류는 이 우선순위를 넘어 기존 측광으로 즉시 복귀하며 30초 3회 복귀 잠금도 유지한다.

## 좌표·시각과 변화 제한

- 기존 modelV2의 양쪽 자차 차선 1/2만 사용한다. 확률≥0.8, 표준편차≤0.3, 4~60m 구간의 유효·단조 투영과 폭 2.2~5.5m를 요구한다. 차선 누락 시 기존 측광을 유지하며 가상의 차선을 만들지 않는다.
- 모델 좌표의 x/y/z를 현재 모델 내부 파라미터와 실제 rpy 보정으로 카메라에 투영한다. 차선 z에 임의 차량 높이를 더하지 않는다. 선택된 FOV의 64×36 밝기 표본을 재사용한다. 차선 밖의 기본 표본도 모두 유지한다.
- modelV2 원본 카메라 EOF≤250ms, 메시지 시각≤200ms를 함께 검사한다. 반복된 오래된 결과는 유효기간을 연장하지 못한다. 광각 FOV 변경 뒤 0.5초는 이전 기하의 출력이 만료되도록 추가 가중치를 허용하지 않는다.
- 행별 차선 경계 이동은 모델 좌표64px/s, 추가 표본 가중치는 최대1이며 경계에서 부드럽게 감소한다. 추가 측광값은 기본 방식 대비±0.125stop, 전체 보조는±0.375stop이다. 기존 0.5s 평활과0.4stop/s 제한을 유지한다. 포화 장면에서는 차선 보조에 의한 추가 증광을 막고 기존 명암 보조의 하이라이트 보호를 보존한다.
- 위 값은 측광 보조의 제한이며 물리적 셔터/게인 변화량이나 최종 인식 정확도의 보장은 아니다.

## 처리 경로와 성능 범위

옵션이 켜져 있을 때만 기존 nice10/SCHED_OTHER 작업자가 modelV2를 추가 구독해100ms 주기로 최신 결과를 읽는다. 설정 확인은250ms다. 카메라 소유 스레드는 한 번의 유한한 원자적 최신값 읽기와 캐시된 표본 계산만 하며 모델/IPC/설정 파일을 기다리지 않는다. 옵션 OFF는 기존250ms 작업자 주기를 사용한다. 추가 추론·CUDA 처리·카메라 워핑·이미지 복사는 없다. 기존 측광 영역을 기본으로 사용하는 경우 기존 영역 계산에 FOV 표본 계산 비용이 더해진다.

측광 객체 크기는 PC 기준13,904→18,960바이트다. 추가 메시지 구독/스케줄링/기존 영역 스캔 및 실기기 전체 추론 지연은 아래 마이크로벤치마크에 포함되지 않는다. 이 옵션이 모델 입력 기하를 바꾸지는 않지만, 실제 노출이 바뀌면 모델 판단도 달라질 수 있다.

- 실제 camerad 번역 단위를 전체 생성 스키마로 컴파일했다. 기존 센서 헤더의 경고 분류만 원래대로 허용했다.

- 네이티브 C++ 투영·차선 폭/확률/산포·NaN·급변·소실·재진입·유효기간·가중치 및 stop 제한, 동시 mailbox 읽기, 기존 실제 프레임 선택과 UI 회귀를 검사했다.

## 실제 영상 GIF의 의미

공식 [commaai 모델 재현 테스트](https://github.com/commaai/openpilot/blob/v0.9.9/selfdrive/test/process_replay/model_replay.py)에 사용되는 공개60초 기록의 원본 road/wide HEVC와 modelV2·liveCalibration을 함께 재생했다. EncodeIdx의 segmentId→camera frameId로 영상을 맞췄고, 원래 EOF와 메시지 발행 시각을 사용했다. 기록된 tizi/OX03C10의 실제 보정값과 기본 모델 FOV를 사용했다. 출처가 다른 영상에 C3X 보정0/80도를 임의로 적용했던 이전 시연은 FOV 검증 근거로 사용하지 않는다.

렌즈당1,196프레임을 실제 C++ 측광 코드로 처리했으며, 녹색은 추가 밝기 가중치, 청록색은 모델 입력 범위다. GIF는 그중2~18초를 원속도로 보여준다. 차선 곡률·차선 품질 소실에 따른 적용과 복귀를 확인할 수 있다. 영상 픽셀 자체를 보정해 노출 개선 화면을 합성하지 않았다. 새 모델 추론이나 물리 센서 폐루프 응답, 야간/터널 출구 실차 인식 개선을 검증한 영상은 아니다.
