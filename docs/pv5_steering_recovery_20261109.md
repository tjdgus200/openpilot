# PV5 선택형 보조력 복귀와 각도 제한 정리

## 2026-11-10 각도 오차 기반 회복 추가

커브에서 운전자가 조향하다 놓을 때의 보조력 회복을 개선하라는 후속 승인이다.
기본 OFF/PV5 angle 전용과 두 시간 설정의 범위·기본값·회차별 고정은 유지한다.
기존 고정 시간 설명은 현재 기준 속도를 뜻하며, ON의 실제 상승률은 아래 범위에서
오차에 따라 빨라질 수 있다. 최대각·각도 변화율·횡가속/jerk·최대 보조력·Panda는
바꾸지 않고 실제 모델 목표각과 제한 후 송신각도 그대로다. Jetson 패키지는 변경하지 않는다.

- 저힘 확인을 통과해야 보조력을 올린다. 예비/확정 운전자 개입 시 기존 양보량을
  즉시 적용하고 가속 증거를 지운다. 남은 힘 비율 0.6 이상에서는 추가 가속하지 않는다.
- `목표각−실제각`과 `제한 후 송신각−실제각`이 모두 유한·같은 방향이어야 한다.
  둘 중 작은 절댓값으로 계산하여 제한 밖 요청만으로 가속하지 못한다.
- 속도·wheelbase·steer ratio로 정규화한 오차 허용폭은
  `clip(degrees(atan(0.3*wheelbase/max(speed²,25)))*ratio, 1°, 5°)`다.
  이것은 설계용 각도 오차 기준이며 실측 횡가속·차선 여유나 EPS 토크가 아니다.
  허용폭~3배 폭 사이에서 추가 가속 요구를 0~1로 연속 보간한다.
- 같은 오차 방향을 0.1초 확인하고 추가 비중은 0.2초당 0~1로 제한한다.
  저힘 확인과 병행하므로 새로 0.1초를 뒤에 덧붙이지 않는다. 오차 감소 시 비중을
  낮추며, 0/불일치/방향 반전·무효 geometry·시간 이상은 오래된 가속을 쓰지 않는다.
- `기본상승률 × [1 + (min(1.5, 기준초/1.0)−1) × 추가비중]`을 적용한다.
  기본 1.5초에서는 최대 1초 기준, 3초에서는 2초 기준이다. 1초 설정은 더 빨라지지 않는다.
  25~250/100Hz 최대 상승은 2.25 CAN 단위/틱이고 상한 250은 유지한다.
  OFF 반환은 고정 1.5초다. 상한에 도달하면 새 오차 계산을 실행하지 않는다.

검증은 실제 controller/CAN 고정 입력 재생과 미보정 피드백 시뮬레이션을 구분한다.
`test_pv5_adaptive_recovery.py`는 확인·증가율·반전·잡음·재개입·무효/만료를 검사하고,
controller 검사는 양쪽 실제 CAN과 각도 불변·기본 OFF/타차종을 검사한다.

`test_pv5_recovery_simulation.py`는 같은 controller/패커에 가정한 20Hz 차로 추종
계획·bicycle 횡운동·2차 EPS를 연결한다. 속도10/15/22m/s, EPS 최대 각가속 가정
180/360deg/s², 지연0/80ms, 일정/0.6초 동안1.5배로 휘는 커브, 좌우 총48조건이다.
wheelbase3m/ratio14.26, EPS gain60·damping14·self-align2 등은 합성 시험값이며
실제 PV5 측정치가 아니다. 실제 신경망을 실행하지 않고 CAN 상한과 모터 토크의
대응도 측정하지 않았다. 현재 모델의 인식 성능이나 실차 이탈 방지 검증이 아니다.
일부 가정 조건에는 변경 후에도 큰 횡오차가 남는다. 전체 사례의 개선/동일/악화와
최대 오차를 함께 공개하고 모든 조건에서 차선을 유지했다고 하지 않는다.
선택적 `PV5_RECOVERY_SIM_REPORT`는 PC 출력 경로이며 차에는 상시 수집기를 넣지 않는다.

## 2026-11-10 사용자 시간 설정과 1.5초 기본값

후속 요청으로 고정 1.2초 ON 램프를 사용자 설정으로 바꾸고 기본을 1.5초로
돌렸다. 아래 고정 1.2초 기록은 당시 이력이며 현재 기본값을 뜻하지 않는다.
캐럿웹 PV5 → 주행 보조 → 단순 조향 보조력 복귀의 상세 화면에 두 항목을 둔다.

- `Pv5SteerReleaseMs`: 100~500ms/50ms 단위, 기본 200ms.
- `Pv5SteerRecoveryMs`: 1000~3000ms/100ms 단위, 기본 1500ms.

PV5 angle+옵션 ON에서만 기존 50프레임 poll로 읽는다. 추가 스레드·신경망·
프레임별 Params 접근은 없다. 각 INT 키의 native 기본값과 웹 범위를 일치시킨다.
누락/손상/음수/범위 밖/간격 밖 값은 기본값으로 복귀한다. 첫 정상 저힘 표본부터
두 시간을 고정하여 진행 중 값 변경이 확인 시간을 줄이거나 램프를 가속하지 못하게 한다.
재개입·예비 개입·확인 중 힘 재상승·입력 이상·기능 전환 후 다음 저힘 확인부터
새 값을 사용한다. 기존 양보·입력 gate·시간 이상 처리·비활성 초기화·모든 한계와
고정 1.5초 OFF 복귀는 유지한다. 기본 OFF와 다른 차량/토크 조향은 기존 출력이다.

25~250/100Hz에서 허용된 ON 최대 상승은 1.0초일 때 2.25단위/틱,
기본 1.5초일 때 1.5단위/틱, 3.0초일 때 0.75단위/틱이다. 회복은 CAN 보조력
상한 증가율이며 실제 핸들 응답이나 차선 회복시간이 아니다. 회복 중에도 허용된
상한으로 목표각을 추종한다. 범위와 기본값의 실차 안전성·조향감은 미검증이다.

차선 이탈 예측에 따른 적응형 가속은 검토만 하고 이번 제어에 넣지 않았다.
모델 목표 경로는 보조력 저하 중 실제 차량의 미래 궤적과 같지 않으므로 이것만으로
1.5초 뒤 차선 이탈을 단정할 수 없다. 추가 설계 시 차량 외곽/차선 경계 여유,
실제 횡운동/조향 추종, 차선/자차 상태 신선도·품질, 의도적 변경과 운전자 개입을
분리해야 한다. 연속 보간·진입/해제 히스테리시스와 회차별 유지가 채터링을 줄일 수
있지만, 폐루프 재현과 실차 검증 없이 이탈 방지·급회복의 안전성을 주장하지 않는다.

PC 검사: 모든 설정 간격/경계·손상값, 확인/복귀 중 변경 고정, 재개입/중단 후
재확인, OFF 및 타차종 불변, 기존 poll 횟수, 두 실제 CAN 경로 상한/목표각을 확인한다.
모델/HUD/FOV/AE/레이더/Panda safety 및 Jetson 배포 파일은 변경하지 않는다.

## 2026-11-10 복귀 속도 조정

사용자 요청으로 단순 복귀 ON의 전체 보조력 상한 회복 기준만1.5초에서1.2초로
줄였다. 아래 최초 도입 설명의 ON1.5초는 이번 변경으로 대체한다. 기본 OFF와
PV5 앵글 조향 범위는 그대로이며, 차량에서 저장된 옵션의 현재 활성 여부는 확인하지 않았다.

실제 조향각 복귀 속도나 폐루프 안정성·조향감은 이 수치로 보장하지 않는다.
기존0.30초 반복 개입 필터와 다른 차종 동작, 모델/FOV/AE/HUD/BLE는 유지한다.

사용자 승인: 제안 2번은 토글로 비교하고 제안 3번은 바로 적용한다.

## 선택형 복귀

`Pv5SimpleSteerRecovery`를 PV5 → 주행 보조에 추가했다. 기존 50프레임 설정
확인을 재사용하고 별도 폴링·스레드·상시 측정은 추가하지 않는다.
OFF는 기존 결합 handover 출력을 그대로 사용한다. ON은 기존 CAN 보조력
상한을 선택하며 목표각이나 모터 토크 명령을 새로 계산하지 않는다.

- 운전자 확정 개입 시 기존 20 CAN 단위/프레임 양보를 유지한다.
- 기존 예비 개입 검출과 최대 10 단위/프레임 양보도 유지한다.
- 기존 0.6 기준 미만 힘을 0.2초 확인한다. 이후 0.6~0.8 구간은 복귀 속도를
  선형으로 줄이고 0.8 이상에서는 증가하지 않는다.
- 복귀 기준은 기존 fallback인 전체 1.5초다. 25~250 범위에서 100Hz 기준
  프레임당 최대 1.5 CAN 단위 증가다. 모델 yStd와 반복 개입 횟수를 이 속도에
  사용하지 않는다. 기존 모델 신선도·유효성 gate는 유지한다.
- ON/OFF는 직전 실제 선택 출력에서 시작한다. OFF로 돌아갈 때 배경의 기존
  상태기가 이미 큰 상한을 계산했더라도 같은 증가율로 이어간다. 운전자 양보는
  전환 중에도 우선한다. 비활성화는 0으로 초기화한다.
- 만료/잘못된 CAN·모델·조향 fault나 시간 이상은 새 복귀로 보조력을 늘리지 않는다.

sunnypilot의 연속적인 복귀 아이디어를 참고했지만 해당 곡선이나 보정값을
복사하지 않았다. 기존 상한과 검출·양보를 재사용한 별도 비교 후보이며,
기존 정상 복귀가 1.5초보다 빠른 구간에서는 새 방식이 더 느릴 수 있다.

## 각도 제한을 간추린 범위

모델 불확실성·저속·큰 목표각 차이의 변화율 제한을
`min(모델 변화율, 속도 변화율, 큰 오차 변화율)` 예산 하나로 묶었다.
큰 각도에서 중앙으로 되돌리는 기존 예외는 그 예산에 기존과 같이 적용한다.
물리 횡jerk 예산과 결합한 뒤 기존 각도 변화율 제한과 횡가속 제한을 수행한다.
어떤 한계나 조건도 제거·완화하지 않으며 목표 클립과 출력 클립은 비활성
측정각 및 물리 제한을 처리하는 역할이 달라 둘 다 유지한다.
따라서 3번은 구조 정리이며 더 강한 조향이나 반응 개선을 주장하지 않는다.
