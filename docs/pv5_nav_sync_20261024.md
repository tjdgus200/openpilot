The owner requested upstream alignment except the following retained behavior.

- Fresh OEM OR comma-local ONNX BSD drives the physical red edges and outer-third
  gradient without a turn-indicator gate. Vehicle alerts remain on top.
- Jetson module power/temperature badge, battery page 8 and its existing display
  diagnostics remain. Power sampling is 0.5 seconds; missing/stale values remain
  unknown. Battery reception remains passive and requires a validated PV5 profile;
  no fabricated profile, diagnostic CAN transmission or vehicle control is added.
- Auxiliary USB input cutoff is asserted before normal AGNOS launch and checked
  before Jetlink. Separate main power remains mandatory. It is a software current
  vote, not electrical isolation during boot ROM/kernel initialization.
- Offroad OR fresh valid Park/zero-speed update permission is retained. A running
  inference engine cannot be replaced onroad merely because the car is in Park.
  Permission loss suspends writes/activation; recovery retries the transfer in the
  same connection. SHA/size/runtime/model validation and rollback remain required.
- This fork selects its own public SHA-256 USB runtime package, not the official
  signed runtime that lacks the PV5 renderer. Existing local USB enrollment is
  required; this change neither installs credentials nor bypasses enrollment.
