# carrot-nav-pv5 alignment, 2026-10-24

Upstream baseline: `3032c4c613cfb958116c231a3d0905a384c2d30f`.
Previous PV5 tip: `afcbe0fcd0ed149fb63f7f3e69edac8ccf2ecdb1`.
The owner requested upstream alignment except the following retained behavior.

- Fresh OEM OR comma-local ONNX BSD drives the physical red edges and outer-third
  gradient without a turn-indicator gate. Vehicle alerts remain on top.
- Jetson module power/temperature badge, battery page 8 and its existing display
  diagnostics remain. Power sampling is 0.5 seconds; missing/stale values remain
  unknown. Battery reception remains passive and requires a validated PV5 profile;
  no fabricated profile, diagnostic CAN transmission or vehicle control is added.
- Auxiliary USB input cutoff is asserted before normal AGNOS launch and checked
  before Jetlink. Separate main power remains mandatory. It is a software current
  vote, not electrical isolation during boot ROM/kernel initialization.
- Offroad OR fresh valid Park/zero-speed update permission is retained. A running
  inference engine cannot be replaced onroad merely because the car is in Park.
  Permission loss suspends writes/activation; recovery retries the transfer in the
  same connection. SHA/size/runtime/model validation and rollback remain required.
- This fork selects its own public SHA-256 USB runtime package, not the official
  signed runtime that lacks the PV5 renderer. Existing local USB enrollment is
  required; this change neither installs credentials nor bypasses enrollment.

Other runtime paths now match upstream, including bounded 32KiB request envelopes,
same-request native AIO writer, completed logical-request queue, negotiated fallback,
DHCP ownership race handling, initial HELLO grace, 2066-element parser precedence,
N16-only map/image staging defaults, and independent regression switches. This is
the newly requested official request writer, not the retired PV5 async writer.
No multiple-model-frame pipeline or new model selection is introduced.

Previous PV5 Wi-Fi/auxiliary-CPU runtime overrides are removed. Lane/BSD inference
is comma-local and the HUD uses the official USB cadence. Automatic brightness and
offroad HUD gating now follow upstream; the previous always-visible/minimum-10%
override is removed. Saved user settings are not rewritten. Previously installed
OS/network configuration is not erased by this source synchronization.

HUD-only read-only statistics remain outside inference and do not modify model
inputs or GPU state. The battery field and final-snapshot timestamp remain in the
USB record. The standalone package import path fix remains necessary for the
PV5 renderer. Full upstream driving/CAN/planning code is retained unchanged.

PC Linux validation: 1631 passed, 3 skipped for the integrated Jetlink/model
suite; 127 navigation/scene/screen-setting tests passed. New cross-layer cases
verify a multi-envelope PV5 HUD record, replay suppression, exact bytes, battery
values, indicator-free BSD and stale rejection. Real Linux AIO regular-file
tests and simulated timeout/reconnect/rollback checks are part of that suite.
Three actual-renderer synthetic previews retain the battery, W/temperature,
full-height BSD edges and gradient. Values in these previews are invented.
Korean/English settings documentation checks pass.

The new source package and public download hashes are checked separately before
the branch selects it. No automatic auxiliary ONNX probe is introduced.
PC tests cannot establish physical USB/PMIC behavior, live TensorRT performance,
20Hz operation, road safety, or an absence of reboot issues on the actual devices.
