# 콤마 로컬 ONNX와 USB HUD 복원 — 2026-10-22

`carrot-nav-pv5`는 사용자 요청에 따라 Wi-Fi 보조 영상/결과 경로를 중단한다.
차선·시각 BSD 서비스, 웹 화면, 결과 병합과 설정 범위는 공식 `carrot-nav`
`ec36d5e5`를 따른다. 주행 모델 N16, GPU 상태 유지, 공식 직렬 USB 전송,
USB 완료 우선순위, P단·정지 업데이트 조건은 변경하지 않는다.

## 실행 및 데이터 경로

1. 기존 온로드 준비 조건과 `ShareData`에 따라 콤마에서 차선 ONNX를 실행한다.
   시각 BSD는 별도 `OnnxBsdEnabled`와 기존 ROI/차로 폭 조건을 따른다.
2. `card.py`가 방향별로 **차량 BSD OR 유효한 시각 BSD**를 병합한다.
   ONNX 미감지·꺼짐·실패·오래된 결과는 차량 BSD를 지우지 않는다.
3. 병합된 `carState.leftBlindspot/rightBlindspot`는 기존 HUD 스냅샷에 포함된다.
   별도 BSD 패킷/타이머/소켓을 추가하지 않는다. 스냅샷 생성은 기존 최대 10Hz이고,
   USB 전송은 공식 HUD 전송 구간과 기존 중복·만료 검사를 그대로 따른다.
4. Jetson HUD는 같은 방향 깜빡이와 신선한 BSD에 즉시 밝은 빨간 선을 표시한다.
   기존 2Hz 밝기 변화, 바깥 1/3 그라데이션, 300ms HUD 신선도 검사는 유지한다.

차선 기본 간격은 400ms, BSD는 250ms이고 최소 설정값은 각각 50ms다.
이는 공식 값의 복원이며 기존 저장된 간격/토글/ROI는 변경하지 않는다.
공식 BSD 후속 검사와 CPU 배치/OpenCV 설정도 복원한다. 콤마 CPU 계산 부하는
원격 추론 때보다 늘 수 있으므로 주행 성능 향상이나 무영향을 주장하지 않는다.

Jetlink 세션에서 보조 Wi-Fi 작업을 더 이상 시작하지 않고 HUD Wi-Fi 폴백도
사용하지 않는다. 기존 네트워크 설정은 SSH/인터넷용으로 유지한다. 호환용 원격
클래스와 Jetson 수신기는 남아 있지만 현 콤마 경로에서는 협상/호출하지 않는다.
`v_asm_inference.py`의 `predict_square` 함수 분리도 구 수신기 호환용으로 유지하며,
로컬 입력과 추론 계산은 공식과 동일하다.

## 적용

콤마 브랜치를 업데이트하고 정상 재시작하면 적용된다. 이미 선택된 Jetson
`b21f1f4c` 패키지는 USB HUD를 지원하므로 패키지/선택 manifest를 바꾸지 않는다.
USB HUD 기능을 광고하지 않는 구형 Wi-Fi 전용 수신기는 자동 우회하지 않는다.
진행 중인 구 Wi-Fi 세션은 정상 재시작으로 종료하고 새 세션에서 시작하지 않는다.

## 검증 범위

PC 검사는 실제 CPU ONNX 모델, 공식 차선/BSD/ROI/토글/NV12 회귀 검사,
방향별 차량·시각 BSD 조합과 만료 결과의 USB 직렬화/경고 표시를 다룬다.
USB HUD 중복/만료/크기 제한과 내비 전송 구간 검사도 유지한다.
이는 새 버전의 실제 콤마 CPU 부하, Jetson 20Hz, 실차 안전성 검증을 대신하지 않는다.

### 완료한 검사와 장치 적용

- 커밋 `489c7c9f`를 연결된 오프로드 콤마에 Git fast-forward로 설치했다.
  관리 프로세스가 이전 모듈을 보관하므로 자식만 재시작하지 않고 콤마를 정상
  재부팅했다. 이후 USB `ready`/오류 없음이 2초 간격 5회 연속 확인됐고,
  `hud_publisher.py`는 실행되며 `vision_cpu.py` 송신 작업은 없었다.
- Jetson은 기존 `b21f1f4c`를 사용한다. 선택 manifest SHA-256은 설치 전후
  `862aadbe73d39f205f730e68ffd8de06072228c58f9e8e4391efa698e437069a`로 같다.
  콤마 Git HEAD는 Jetson 설치 버전 선택에 사용하지 않는다. 같은 패키지의 등록
  확인은 읽기 전용이며 이미 설치된 버전에는 새 후보 실행 검사를 시작하지 않는다.
- 별도 차선/BSD CPU 모델 실행을 설치 필수 조건으로 복구하지 않았다.
  기존 새 인터프리터의 `server` import 검사, HUD 진입점 검사, 주행 GPU 모델
  검증과 실패 시 이전 버전 보존은 유지한다. 검증을 무조건 통과시키지 않는다.
- 로컬 ONNX·HUD 164개, CPU 모델/세션/Wi-Fi 호환 79개, USB 설치·롤백 103개,
  문서/Wiki 생성기 44개 검사가 통과했다. Wiki 생성 검사는 오류 0이며,
  기존 카탈로그의 빈 설명 경고 28개는 이번 변경과 무관하다.
- [GitHub CI 39748572797](https://github.com/tjdgus200/openpilot/actions/runs/39748572797)
  의 Linux 통합/설치/격리 저장소/네트워크 검사와 Windows 설치기 검사가 통과했다.

실제 HUD 출력 연결 상태는 `false`였으므로 화면 표시를 눈으로 확인했다고
보고하지 않는다. 이번 급한 적용에서는 온로드 카메라·크루즈·맵 부하 시험을
새로 실행하지 않았다. 이전 전체 재부팅의 원인은 확정하지 않았으며, 다른 새
패키지의 향후 검증 실패나 전원/커널 문제까지 방지했다고 주장하지 않는다.
