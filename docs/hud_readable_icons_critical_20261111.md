# 안내 아이콘·크리티컬 화면 개선 — 2026-11-11

기존 배포48eb4236의 실제 콤마3X·Jetson 렌더 검사에서 확인한 추상 도형,
PV5 부주의 경고/속도칸 겹침, 크리티컬 표현 차이를 수정한다.

## 표시 변경

- 단속 카메라·셔터는 기존 정적 이미지를 유지한다.
- 끼어들기 경계는 진입 화살표/차량, 추적은 대상 차량/괄호, 감속은 차량/제동 표시,
  구간 단속은 두 측정 지점/거리, 보호구역은 보행자/횡단 표시로 구분한다.
-128×480 흰색/알파 아틀라스의128×96 타일5개를 한 번 로드하고 재사용한다.
  PNG11,072바이트, RGBA240KiB. 대상 안내의 점 변형·반복 캐시는 생성하지 않는다.
- 좌/우 차선변경, 커브·방지턱의1초 변형/2.5초 최대8% 반복은 유지한다.
  문구·실제 데이터 판단·220ms 진입/퇴장·최소 유지·상황 종료·FPS는 유지한다.
- PV5 콤마3X의 일반 부주의 패널을 속도칸 오른쪽으로 옮긴다. 긴 문구도 그 폭에 맞춘다.
  다른 차종의 패널 위치/폰트 경로는 유지한다. 삼각형은 즉시 보이고0.36초 확대 후 고정한다.
- 크리티컬 HUD는 첫 프레임부터 전체1920×480을 불투명 빨강으로 덮고,
  큰 흰 경고문·노란 느낌표·수신한 짧은 이유를 표시한다. 일반 정보/하위 팝업은 덮는다.
  이유를 임의로 추정하지 않으며, 빈 제목은 직접 운전 요청으로 대체하고 긴 문구는 폭에 맞춘다.
- 크리티컬 느낌표는 DM 이외의 시스템 오류에도 콤마3X/HUD 모두 표시한다.
  기존 신선도·경고 해제·음량·경고 판정은 유지한다.

검사 수는 중복되므로 합산하지 않는다. 새 아틀라스와 크리티컬 표시는 UI 변경이며
추가 추론·타이머·통신·로깅·OBD 요청을 넣지 않는다. 실제 C3X/Orin 추론 시간이나
실차 안전 검증을 수행한 것은 아니다. 첨부 화면/GIF는 합성 입력을 실제 UI에 넣은 결과다.
차량 설치/재부팅은 미실행이며 새 콤마 코드와 Jetson 패키지를 적용해야 한다.

초기 PC 집중 검사의 추적 상태 fixture 초기화 누락, Windows에서 Linux 의존성을
실행한 환경 오류, 아카이브 probe의 시나리오 간 시간/팝업 상태 잔존을 보완하고
준비된 Linux PC 환경에서 다시 검사했다. 최종 아카이브 결과는 실패/스킵 없이 통과했다.
후속 C3X 긴 문구 폭 맞춤은 Jetson export 범위 밖의 UI 파일에만 있다.
최종 배포 핀/커밋에 필수 검사를 다시 연결한다.
