# 고정 카메라·셔터 아이콘 — 2026-11-11

사용자 요청에 따라 단속 안내(cam/HDA/Waze)의 점 변형과 반복을 제거한다.
콤마3X와 Jetson HUD 모두 같은 고정 카메라·셔터 PNG를 사용한다.
다른 안내의1초 점 변형·2.5초 약한 반복, 팝업220ms 진입/퇴장, 정착 후 최소1초 유지,
상황 유지/종료, 문구·방향·경고 우선순위·현재 화면 FPS는 보존한다.

## 구현과 비용 범위

-128×96 RGBA PNG를 기존 UI 리소스 준비 때 한 번 로드하고 기존 종료 경로에서 해제한다.
- PNG4,667바이트, RGBA 텍스처48KiB. 표시 중 기존 렌더 호출에서 이미지 한 장을 재사용한다.
- 단속 아이콘은 좌표 표·반복 캐시·프레임별 삼각함수/점 생성을 사용하지 않는다.
- 기존12개 원 그리기 API 호출을 텍스처 사각형1개로 바꾼다. 실제 GPU 배치/호출 수나
  전체 GPU 시간과 같은 뜻은 아니며, raylib의 배칭을 포함한 실기기 성능은 측정하지 않았다.
- 새 추론·타이머·스레드·IPC·로깅·OBD 요청이 없다. 모델/FOV/제어/OBD/상태 전달 등
  보호 파일17개가 이전 배포 `e7c21e45`와 바이트 단위로 같다.
- 파일 누락/텍스처 실패 시 안내 문구는 남는다. 모델 입력·판단·차량 제어 경로는 변경하지 않는다.

## 검증

비교 기준은 `e7c21e45`, PC의 합성 입력으로 실제 UI 렌더러와 정확한 배포 아카이브를 실행했다.

검사 수는 중복되므로 합산하지 않는다. PNG는 합성 입력을 실제 렌더러로 표시한 결과다.
정적 아이콘에는 시간 변화 GIF를 추가하지 않는다. 실제 C3X/Orin 추론 영향이0이라고
보장하지 않으며, 새 콤마 코드와 모델별 Jetson 패키지 적용이 필요하다.
