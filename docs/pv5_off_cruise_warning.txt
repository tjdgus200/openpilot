문서 시점: Git 푸시 전 PC 검증 완료 기록. 이후 푸시 여부와 차량 설치 여부는 별도로 확인한다.

PV5 크루즈 OFF 충돌 위험 경고 — 구현 및 PC 검증 결과

상태
코드 구현과 PC 검증 완료. 차량 설치·재부팅·원격 접속·Git 커밋·푸시는 하지 않았다.
제동·조향·기존 끼어들기 선택·긴급 제어 판단을 변경하지 않는 화면/음향 전용 보완이다.

경고 규칙
- 현재 PV5 CAN-FD 카메라 SCC + openpilot 종방향 설정에서만 적용한다. 대시캠/passive와 다른 차종은 대상이 아니다.
- openpilot와 차량 크루즈가 꺼져 있고 D단, 정차/주차브레이크/홀드가 아니며 추정·원시 속도 모두 2m/s 이상인 상태만 새 경고를 표시한다.
- CarState와 원본 SCC 입력이 각각 100ms 이내이며 CAN·CRC·연속 카운터가 정상이어야 한다. 원본 카메라 버스만 사용하고 송신 에코는 쓰지 않는다.
- 순정 SCC 정상 Main/Mode 및 대상 표시, 유효 거리·상대속도와 함께 raw 감속 요청 -3m/s² 이하, 접근속도 1m/s 이상, 거리 40m 이하, 일정 상대속도 가정 TTC 1.5초 이하, 접근속도²/(2×거리) 1.25m/s² 이상을 모두 요구한다.
- 단순 근접, 멀어지는 대상, 약한 SCC 요청, 측정 가속도 잡음만으로는 울리지 않는다. 급접근을 숨기지 않도록 가속·브레이크 페달만으로 일괄 차단하지 않는다.
- 검증된 양의 근거리 0.1~0.5m도 유지한다. 0·미확인 거리·오래된 값은 거부한다. 더 강한 유효 감속 요청도 검출한다.
- 같은 위험의 소리는 최초 1회, 위험도가 더 높아질 때 추가 1회다. 정상 자료로 위험 해소가 1초 확인되면 재무장한다. 통신 누락·무효 값만으로 재무장하지 않는다.
- 정차·크루즈 ON 중에도 정상 비위험 자료는 재무장에 반영하여 이후 새 위험의 소리가 빠지지 않게 한다.
- 기존 FCW/AEB·즉시 해제 경고가 더 높은 우선순위를 가진다. 새 경고만으로 AI 분석/Discord 제보를 깨우지 않는다.

검증 결과
- 중복 제거 PC 회귀시험: 4,255 통과, 실패 0, 스킵 2.
- 보관 고유 로그 145개 최종 코드 재생: 145 성공, 실패/스킵 0.
- 사용자 확인 끼어들기 위험: 기존 경고 0구간 → 수정 후 1구간. 최초 및 위험도 상승 소리 2회.
- 원본 강한 SCC 요청 47개가 모두 경고 구간에 반영됐고, 가속페달 입력 중에도 94개 판단 tick에서 유지됐다.
- 원본 요청부터 첫 경고까지 약 7.26ms는 기록 생성 시각을 정렬한 PC 재생값이다. 실제 전달·표시·스피커 지연을 측정한 값이 아니다.
- 다른 144개 로그에서 추가 경고 0. 869,716개 CarState의 기존 필드 불변.
- 10,000개 합성 입력에서 기존 SCC 입력 유효 판정·감속 결정·송신 패킷 차이 0.
- 기존 감속/허용 함수 7개와 컨트롤러·송신·상태기계 등 비교 대상 파일 동일성 확인. 기존 끼어들기·긴급 경고 회귀 통과.
- 초기 시험에서 재무장/오래된 자료 처리 문제를 발견해 수정했고, 정차·크루즈 전환 및 재생시각 정밀도 회귀를 추가했다. 누락된 시험 생성 DBC를 복원한 뒤 관련 시험도 통과했다.

남은 한계
오경고 0이나 모든 충돌 위험 검출을 보장하지 않는다. 실제 위험으로 확인한 강한 SCC 사례는 1건이며 다른 144개를 완전한 정상 정답 데이터라고 간주하지 않는다. 원본 SCC가 유효한 강한 요청을 내지 않는 위험은 이 보완 경로로 검출하지 못할 수 있다. 정지/저속 영역은 새 경고의 대상이 아니며 기존 모델 FCW는 그대로 유지한다.
TTC는 일정 상대속도 가정의 선별 값이고 실제 충돌 확정·정밀 경로 예측이 아니다. 순정 AEB 작동이나 충돌 방지가 보장된다는 뜻도 아니다.
실차 주행·표시·스피커·장치 지연·전체 부하 검증은 미실행이다. 로그별 재생은 독립 시작이며 경계 연속 동작은 합성 lifecycle 시험 범위다. 선택적 native CAN 확장 2건은 미빌드로 스킵했고, 실제 production Python CANParser/DBC를 사용했다. 전체 차량 매트릭스 시험과 Ruff는 의존성 부재로 실행하지 않았다.
