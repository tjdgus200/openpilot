# PV5 조향각 한계 경고

기존 `조향 요구량 높음`은 앵글 제어에서 조향각 한계 검출이 아니었다.
`angle_steering_demand()`가 속도·목표 곡률·롤로 계산한 횡가속도 요구를
`CarParams.maxLateralAccel`로 나눈 값이 80% 이상이면 표시하며, 90% 이상과
신선한 영상 DM 부주의 판단이 겹치면 전방주시 문구와 경고음을 사용한다.
100%가 기계적인 조향 끝이나 조향각 100%를 뜻하지 않는다.

## 별도 한계 검출

새 경고는 PV5의 실제 `angleState`와 `steerControlType=angle`, 활성 `latActive`에서만 사용한다.
`carControl`, `controlsState`, `carState`, `carOutput`은 수신 및 원본 타임스탬프가
모두 300ms 이내여야 한다. 이전 주행 데이터는 콤마 UI에서 제외한다.
CAN 유효성, 운전자 조향 개입과 임시/영구 EPS 오류도 확인한다.

한계는 Hyundai `CarControllerParams.ANGLE_LIMITS.STEER_ANGLE_MAX`에서 읽는다.
현재 코드는 핸들 명령 기준 ±175°이며 앞바퀴 각도나 물리적 EPS 최대각이라는 뜻은 아니다.
전송된 명령이 이 한계에서 0.5° 이내, 측정 각도가 한계에서 3° 이내이고,
제어기의 목표각이 같은 방향으로 한계 및 측정각보다 3°를 넘게 더 필요할 때 level3을 표시한다.
목표각은 기존 모델 기반 제어기의 `carControl.actuators.steeringAngleDeg`다.
미래 궤적 전체를 새로 추론하거나 예측하는 기능은 추가하지 않았다.

`조향각 한계 / 직접 조향하세요`를 콤마 3/3X와 Jetson HUD에 즉시 빨간 두 줄 팝업으로 표시한다.
상황이 계속되면 유지하며 기존 최소 정착 1초 및 종료 시 위로 이동하는 동작을 보존한다.
DM 부주의 여부 없이 콤마에서 한 번 경고음을 재생한다. 기존 전방주시 경고에서
각도 한계로 높아질 때도 같은 WAV를 처음부터 재생한다. 차량 경고와 통신 타임아웃 경고음이
우선하며 대기하던 조향 사유가 사라지면 뒤늦게 재생하지 않는다.
Jetson에는 기존 경고 정수 필드만 전달하며 DM 원본이나 추가 추론 요청은 보내지 않는다.

## 제어 한계와 검증 범위

±175° 및 속도에 따른 각도·변화율·횡가속도·jerk 제한, EPS 토크 상한,
운전자 개입과 safety 제어는 수정하지 않았다. 앵글 방식도 EPS 모터의 힘과
응답 한계가 있으므로 명령 방식만으로 제한 해제의 타당성을 판단할 수 없다.
`values.py`의 LFA 관련 주석은 실제 PV5 EPS의 최대각을 검증한 자료가 아니다.

이 경고는 속도에 따른 더 작은 각도 한계나 EPS 추종력 부족 전체를 진단하지 않는다.
한계 접근 전의 미리 경고나 끼어들기 대응 성능도 보장하지 않는다.
실차 EPS·CAN, 스피커 음량 및 표시 타이밍은 PC 검사로 검증할 수 없다.

필수 PC 검사에 양방향/반대 방향·복귀·각속도 지연·NaN/Inf·신선도·수동 조향·EPS 오류,
경고음 에피소드/격상/우선순위와 HUD level3 수신·만료를 포함한다.
다섯 모델 패키지는 동일한 새 HUD 경고를 실제 네이티브 렌더러로 검사하고 배포한다.
