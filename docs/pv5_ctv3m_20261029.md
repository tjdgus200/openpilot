# CTV3M for the PV5 model library

The owner requested CTV3M `bf3e3631b3` and explicitly selected comma.ai's
Hugging Face distribution for this addition. Existing N16/Flip Flop sources,
default N16 selection, signed NAS policy and public verification keys remain.

The [official source commit](https://github.com/commaai/openpilot/commit/bf3e3631b3f91d92a1020a5e0dd4298b93ff4244)
selects the precompiled eGPU artifact for checkpoint `f78ed37d`. Its SHA-256 is
`4937fc6f04367b28328fe3bc0d1463a245725d039ddaab29406cc565fd5c8ed4`
and length is 773,082,315 bytes. The repository-owned eGPU manifest pins that
object in comma.ai's public Hugging Face bucket; the PKL is not executed by
the PC review. Device-side precompiled validation remains required.

The [official ONNX](https://huggingface.co/commaai/openpilot_driving_models/blob/84c72ed5381a64b8630890b861cddb5adf5ae8aa/f78ed37d-afad-4dbc-8050-40ea885eedde/12864/big_driving_supercombo.onnx)
is fixed to repository revision `84c72ed5381a64b8630890b861cddb5adf5ae8aa`.
It is 766,354,845 bytes and hashes to
`404a18cfd86d29637d20c697dfde245bb47c666ae016730ab674c65f4d1e1aa4`.
The full downloaded file was hashed and its declared inputs, outputs and
output slices matched the extracted metadata. Original ONNX full checking and
the existing TensorRT preparation patch plus full checking passed. The patch
removed the single tinygrad Contiguous node; no custom domains remained.

Its stateful image/desire/features contract and output slice layout equal the
current Flip Flop contract. It has no map/navigation inputs and does not add
NOO. It keeps the non-N16 staging path: N16 output projection, native image
cast and direct map optimization are not forced onto this model.

CTV3M is offered only with a matching PV5 USB runtime, using its own source
commit so installed bootstraps do not confuse it with another model. There
is no official signed CTV3M Jetson host release in this checkout; absence of
the PV5 pin fails closed. No signature is invented or signature check removed.

Save the choice and reboot both comma and Jetson while parked with ignition
off. Existing permission, model hash/size verification, TensorRT probe and
previous-release rollback remain. Selection cannot replace a running engine.
BSD, W/temperature, battery8, BLE, Q92/FPS and USB input-current protection are
preserved; only the chosen model is loaded into GPU memory.

The PC review covers parsing, exact input conversion, recurrent feedback,
reset and non-finite rejection. It does not establish real TensorRT output,
20Hz timing, thermal behavior or driving quality. No vehicle/device changes
were performed during this review.
