# 캐럿 원본과 PV5의 레이더 전체 경로 비교 — 2026-11-10

후속 사용자 승인: 이 감사 이후 [PV5 신호 정차용 가상3m 송신 객체](pv5_signal_stop_object_20261110.md)를
별도 도입한다. 아래 소스 비교·검증은6c282e37의 당시 상태이며, 가상 객체의
보류 결정은 이 후속 기능에 한해서 대체된다. 실측 레이더 처리의 동일성과
Tesla·별도 차량 고장 감시의 기존 분류는 유지한다.

사용자 요청은 레이더 트랙 수신부터 앞차 감지·반응까지 원본과의 차이를 확인하고,
실제 레이더 처리에서 빠진 부분이 있으면 적용하는 것이다. 비교 기준은 원격에서
확인한 `ajouatom/openpilot:carrot-wip`의 `c8454993d2dbebe79010dcea0f3bfc5954f37222`,
우리 실행 코드 기준은 `6c282e3734ce9b5dc37cc246ef375496da3bf499`다.

## 결론

감사 대상 실행 코드·공통 보조 함수50개 파일은 원본과 전체 내용이 동일했다.
`RadarData`와 `RadarState` 스키마도 동일하다. 직전 변경에서0.20초 비전 전환의
PV5 제한을 제거한 뒤, 실제 레이더 처리에 추가로 가져올 누락은 발견되지 않았다.
이번 감사에서는 차량 실행 코드·설정·모델·Jetson 패키지를 변경하지 않았다.

[파일별 비교 해시와 검사 요약](pv5_radar_audit_20261110.json)은 공개 소스의
경로·SHA-256·커밋과 검사 건수만 담으며 차량 로그·CAN 원문·기기 식별정보는 담지 않는다.

## 남아 있는 인접 차이와 분류

- 재생 도구는 차종 메타데이터를 추가 보존하고 캐시 버전6을 사용한다.
  실제 재생 컨트롤러의 기본 정책은 원본과 같고 차종으로 정책을 켜거나 끄지 않는다.
- 원본의 `signalStopObject`는 저속 신호 정차 때 송신 SCC에 거리3m·정지 물체
  정보를 넣는다. 코드 설명대로 실제 레이더 관측이나 planner 앞차가 아니다.
  이 별도 신호 정차 기능은 기존 보류 상태를 유지한다. 실제 레이더 차량이
  존재하는 경로의 개선으로 분류하거나 이번 감사만으로 도입하지 않는다.
- 원본 planner/MPC에는 Tesla CAN 신호등 정차 분기가 더 있다. 원본 factory도
  Hyundai/PV5에서는 객체를 생성하지 않는다. 다른 차종 전용 변경은 제외한다.
- 원본의 별도 Panda CAN/Casper SCC 고장 감시는 전체 제어 허용·경고를 바꾸는
  기능이며 실측 레이더 트랙/매칭의 차이가 아니다. 기존 레이더 입력 유효성·만료
  처리는 동일하지만 전체 고장 차단 시스템까지 같다고 주장하지 않는다.
- 순정 클러스터 색상·BSD·중앙 보정·선택형 조향 복귀는 사용자 보존 기능이다.
  이 표시/조향 차이 때문에 레이더 감지나 앞차 선택을 원본으로 덮어쓰지 않는다.

## 검증 결과와 한계

- 37개 파일의 레이더·Bosch/Mando/CAN-FD 파서·트랙·앞차·끼어들기·정지차·
  빠른 갱신·종방향 보조·SCC 회귀: **2,724 passed,0 failed,0 skipped**.
- 원본/대상 생산 MPC update의 같은 입력108개 조건에서 solver 입력 배열,
  목표 참조·선행차 선택 출처가 동일했다. 기록용 solver를 사용했으므로
  네이티브 최적해·폐루프 차량 반응·실제 제동 성능 검사는 아니다.
- 같은 카운터 상태의 독립 CAN 패커로 속도·거리·차량 유무·활성·정차128개
  조건을 비교했고 전체 송신 바이트와 적용 가속도 값이 같았다.
  가상 신호 정차 객체 요청은 OFF이며 이 기능이 있을 때의 동일성을 주장하지 않는다.
- 준비된 PC CAN 파서/패커/DBC 로더 소스가 대상 저장소와 같은 것을 확인했다.
  누락된 생성 DBC2개는 원본/대상 내용이 같은 generator로 작업 전용 경로에
  생성했다. 공유 테스트 폴더나 실행 중인 외부 시뮬레이션은 변경·종료하지 않았다.
- 차량 실행 코드가 같으므로 다섯 모델 보존 검사는 직전 실행 코드 커밋의
  1,709 passed 결과를 참조한다. 이번 감사의2,724건과 일부 중복되므로 합산하지 않는다.
  코드 출처·검사 목록·짝지은 비교·JUnit은 로컬 작업 증거 폴더에 보관한다.

이번 작업은 콤마/Jetson에 접속하거나 설정을 쓰지 않았다. 실제 RF·센서·CAN/EPS·
USB 지연·주행 감속 성능을 검증하거나 원격 CI 통과로 간주하지 않는다.
